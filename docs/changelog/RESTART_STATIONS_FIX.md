# Исправление перезапуска станций и управления невыбранными станциями

## Дата: 23 декабря 2025

## Проблемы

### Проблема 1: Перезапуск не работал при завершении квиза
При завершении квиза команды перезапуска не доходили до станций на странице финальных результатов.

### Проблема 2: Невыбранные станции переходили на player.html
При запуске квиза на выбранных станциях, невыбранные станции тоже показывали экран подключения к комнате.

## Причины
1. **Неправильный порядок операций** - комната и игроки удалялись ДО повторной отправки команд
2. **Ненадежное определение IP** - функция `getSocketIp` не всегда работала корректно
3. **Избыточность** - команды отправлялись 7 раз, но большинство попыток не находили соединения

## Решение

### 1. Улучшена функция `getSocketIp` (server.js)
- Добавлены 4 способа определения IP с приоритетами
- Улучшена обработка IPv6-mapped IPv4 адресов
- Добавлено логирование для отладки

### 2. Создана упрощенная функция `sendRestartCommandsToStations` (server.js)
- Использует только поиск по IP для максимальной надежности
- Отслеживает отправленные socketId, чтобы не дублировать
- Отправляет команды на все соединения с IP станции
- Отправляет старые события для обратной совместимости

### 3. Переписан обработчик `local-end-quiz-and-reset` (server.js)
**Новый порядок операций:**
1. Отправить команды перезапуска (пока все данные доступны)
2. Подождать 500мс
3. Повторно отправить команды (для надежности)
4. ТОЛЬКО ПОТОМ удалить комнату и игроков
5. Очистить состояние станций

**Результат:** Команды отправляются только 2 раза вместо 7, но с гарантированной доставкой.

### 4. Добавлены подтверждения получения команд
- **На клиенте** (`player.html`, `station.html`): отправка события `local-station-command-received`
- **На сервере**: обработчик подтверждений с логированием задержки доставки

### 5. Улучшена проверка `isLocalStation` в `player.html`
- Добавлена проверка `roomParam` из URL
- Работает даже когда `roomCode` равен `null` после удаления комнаты
- Обновлены все обработчики событий

### 6. Автоматический перезапуск в `local-host.html`
- Станции автоматически перезапускаются через 3 секунды после завершения игры
- Работает даже если пользователь не нажимает кнопку вручную

### 7. Исправлена отправка команд невыбранным станциям при запуске квиза (server.js)
- Используется функция `sendRestartCommandsToStations` для надежной доставки
- Команды отправляются на ВСЕ зарегистрированные станции (не только `connected=true`)
- Невыбранные станции получают команду `waiting` и остаются на `station.html`

### 8. Убран автоматический перезапуск через 3 секунды (local-host.html)
- Перезапуск теперь происходит только при нажатии кнопки
- Даёт больше контроля пользователю

### 9. Перезапуск всех станций независимо от статуса (local-host.html)
- При перезапуске команды отправляются на ВСЕ станции (1-9)
- Сервер сам находит активные соединения по IP-адресу
- Работает даже если станция показывается как `connected=false`

## Результат

✅ Команды доставляются на все соединения станций  
✅ Работает на странице регистрации, во время игры и на странице финальных результатов  
✅ Не зависит от состояния `players` Map или `rooms` Map после удаления  
✅ Надежная доставка даже при переподключениях  
✅ Минимум избыточных отправок (2 вместо 7)  
✅ Подтверждения получения команд для отладки  
✅ Невыбранные станции остаются на `station.html` при запуске квиза  
✅ Перезапуск работает для всех станций независимо от статуса подключения  

## Тестирование

Для проверки:
1. Запустите квиз на станциях через `local-host.html`
2. Дождитесь завершения игры (страница финальных результатов)
3. Нажмите кнопку "Перезапустить станции" или подождите 3 секунды
4. Проверьте логи сервера - должны быть сообщения о подтверждении получения команд
5. Станции должны вернуться на `station.html`
