## 📋 Описание разделов

### `/public` - Веб-интерфейс
Содержит все файлы, которые отдаются клиентам через веб-сервер:
- HTML страницы приложения
- JavaScript для клиентской части
- CSS стили
- Изображения и шрифты

### `/server` - Серверный код
Логика работы сервера, разделенная по модулям:
- **dmx/** - управление DMX освещением
- **routes/** - HTTP API endpoints
- **utils/** - вспомогательные утилиты

### `/data` - Данные
Хранилище данных приложения:
- **quizzes/** - конфигурации квизов в формате JSON
- **questions/** - текстовые файлы с вопросами

### `/hardware` - Аппаратное обеспечение
Документация и прошивки для аппаратных компонентов:
- **esp32/** - контроллер DMX на базе ESP32

### `/docs` - Документация
Вся документация проекта, организованная по темам:
- **setup/** - инструкции по настройке и развертыванию
- **architecture/** - описание архитектуры системы
- **dmx/** - документация по DMX системе
- **guides/** - руководства для пользователей и разработчиков
- **design/** - дизайн и брендинг
- **changelog/** - история изменений

### `/scripts` - Скрипты
Утилиты для автоматизации задач:
- Запуск и развертывание
- Создание квизов
- Диагностика оборудования

### `/tests` - Тесты
Тестовые файлы для проверки функциональности:
- Тесты подключения ESP32
- Тесты DMX системы
- Тесты джойстика

## 🔄 Логика организации

1. **Разделение по типу**: код, данные, документация, скрипты разделены
2. **Модульность**: серверный код разбит на логические модули
3. **Масштабируемость**: легко добавлять новые квизы, страницы, модули
4. **Понятность**: названия папок и файлов отражают их назначение
5. **Стандартность**: структура следует общепринятым практикам Node.js проектов

## 📝 Примечания

- Все пути в коде обновлены после реорганизации
- Скрипты запускаются из корня проекта: `./scripts/start.sh`
- Документация доступна через README.md с ссылками на соответствующие разделы
- Временные файлы удалены, структура очищена
