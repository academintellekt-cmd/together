## Логотип

### Основной логотип "ВМЕСТЕ"

#### Структура логотипа
- **Текст**: "ВМЕСТЕ" (кириллица)
- **Шрифт**: Days One, Bold (700)
- **Цвет**: `#373639` (темно-серый)
- **Размер**: Адаптивный, зависит от контекста использования

#### Декоративные элементы
- **Две точки над буквой "И"**:
  - Левая точка: `#fececd` (светло-розовый)
  - Правая точка: `#d6fbbf` (светло-зеленый)
  - Размер: Пропорционально размеру логотипа
  - Расположение: Над центральной частью буквы "И"
  - Форма: Круглые

#### Использование
- Основной логотип на главной странице (Frame 2)
- Упрощенная версия в футере
- Минималистичная версия для мобильных устройств

#### Варианты логотипа
- **Полный**: С декоративными точками
- **Упрощенный**: Только текст без точек
- **Монохромный**: Для печати и одноцветных применений

## Типографика

### Основные шрифты

#### 1. Montserrat (Основной текст)
- **Использование**: Основной текст, формы, сообщения, описания
- **Начертания**: 400 (Regular), 600 (SemiBold), 700 (Bold), 800 (ExtraBold)
- **Примеры применения**:
  - Текст в body
  - Поля ввода (input, textarea, select)
  - Сообщения об ошибках и успехе
  - Статусные индикаторы

#### 2. Days One (Заголовки и акценты)
- **Использование**: Заголовки всех уровней, кнопки, карточки, важные элементы интерфейса
- **Начертания**: 400 (Regular), 600 (SemiBold), 700 (Bold)
- **Особенности**: 
  - Все заголовки (h1-h6)
  - Кнопки и элементы управления
  - Заголовки карточек квизов
  - Таймеры
  - Варианты ответов
- **Стили**: 
  - `text-transform: uppercase` для кнопок
  - `letter-spacing: 0.5px` для улучшения читаемости

#### 3. Caveat (Декоративный текст)
- **Использование**: Декоративные фразы, подписи, акцентные элементы
- **Начертания**: 400 (Regular), 600 (SemiBold), 700 (Bold)
- **Примеры применения**:
  - Фразы под логотипом (Frame 2)
  - Декоративные фразы в карточках квизов
  - Выделенная информация
- **Особенности**: 
  - Часто используется с `transform: rotate(-2deg)` для игривости
  - Цвет: `#354fba` (синий)

### Размеры шрифтов

Все размеры адаптивные через `clamp()`:

```css
--font-size-xs: clamp(12px, 2vw, 14px)    /* Мелкий текст */
--font-size-s: clamp(14px, 2.5vw, 16px)   /* Обычный текст */
--font-size-m: clamp(16px, 3vw, 18px)     /* Средний текст */
--font-size-l: clamp(20px, 3.5vw, 24px)   /* Крупный текст */
--font-size-xl: clamp(24px, 4vw, 32px)    /* Очень крупный текст */
```

#### Специфические размеры:

- **H1**: `clamp(36px, 6vw, 48px)`
- **H2**: `clamp(28px, 5vw, 36px)`
- **H3**: `clamp(24px, 4vw, 28px)`
- **Заголовки карточек**: `clamp(20px, 4vw, 30px)` - `clamp(24px, 5vw, 36px)`
- **Таймер**: `clamp(32px, 7vw, 48px)`
- **Кнопки**: `clamp(15px, 3vw, 17px)`
- **Варианты ответов**: `clamp(18px, 3.5vw, 22px)`

## Комбинации цветов

- Использование: Предупреждения, важные уведомления, акцентные кнопки

**Комбинация 2: Оранжевая гамма**

- Акцент: `#2fb95d` (Зеленый)

- Использование: Успешные действия, правильные ответы, позитивные состояния

**Комбинация 4: Мятная гамма**
- Основной: `#7cf6c7` (Мятный)

**Комбинация 7: Розово-фуксия**
- Основной: `#f67cab` (Розово-фуксия)
- Акцент: `#fececd` (Светло-розовый)

**Комбинация 8: Желто-зеленая**
- Основной: `#e8f67c` (Желто-зеленый)
- Акцент: `#abf67c` (Лайм)
- Фон: `rgba(232, 246, 124, 0.15)` (Прозрачный желто-зеленый)
- Использование: Энергичные элементы, призывы к действию

### Правила комбинирования

1. **Контраст**: Основной цвет должен иметь достаточный контраст с фоном (минимум 4.5:1 для текста)
2. **Акценты**: Используйте не более 2-3 цветов в одной комбинации
3. **Прозрачность**: Применяйте прозрачность (0.1-0.25) для фоновых элементов
4. **Границы**: Темные границы (`#373639` или `#000000`) для четкости
5. **Текст**: На цветных фонах используйте белый или темный (`#373639`) текст в зависимости от контраста

### Примеры использования комбинаций

#### Карточки квизов
- **Фон**: `rgba(245, 245, 245, 0.85)`
- **Акцент**: Цвет темы квиза (лайм для ГНУ, голубой для Академ)
- **Граница**: `#373639` или цвет темы
- **Текст**: `#373639`

#### Кнопки действий
- **Успех**: Комбинация 3 (Лаймовая гамма)
- **Ошибка**: Комбинация 1 (Коралловая гамма)
- **Предупреждение**: Комбинация 2 (Оранжевая гамма)
- **Информация**: Комбинация 5 (Голубая гамма)

#### Декоративные элементы
- **Floating элементы**: Используют комбинации с прозрачностью
- **Иконки**: Яркие цвета из палитры рисованного стиля
- **Акценты**: Комбинации теплых или холодных тонов в зависимости от контекста

## Эмоциональные элементы

### Рисованные лица (Drawn Style Faces)

Эмоциональные элементы используются для передачи настроения и создания дружелюбной атмосферы в интерфейсе.

#### Набор эмоций

**1. Задумчивое/Неуверенное лицо**
- **Выражение**: Приподнятые брови, слегка открытый рот, наклон головы
- **Использование**: Состояния загрузки, размышления, неопределенности
- **Цвета**: Нейтральные тона или комбинация 5 (Голубая гамма)

**2. Уверенное/Самодовольное лицо**
- **Выражение**: Прищуренные глаза, легкая улыбка
- **Использование**: Успешные действия, достижения, позитивные результаты
- **Цвета**: Комбинация 3 (Лаймовая гамма) или комбинация 8 (Желто-зеленая)

**3. Нейтральное/Удивленное лицо**
- **Выражение**: Широко открытые глаза, маленький прямой рот
- **Использование**: Информационные сообщения, нейтральные состояния
- **Цвета**: Нейтральные тона или основной цвет текста

**4. Очень радостное/Взволнованное лицо**
- **Выражение**: Широко открытые глаза, широко открытый рот с языком
- **Использование**: Празднование успеха, большие достижения, финальные результаты
- **Цвета**: Комбинация 3 (Лаймовая гамма) или комбинация 8 (Желто-зеленая)

**5. Злое/Расстроенное лицо**
- **Выражение**: Нахмуренные брови, сжатые зубы, опущенный рот
- **Использование**: Ошибки, неудачи, предупреждения
- **Цвета**: Комбинация 1 (Коралловая гамма)

**6. Скучающее/Равнодушное лицо**
- **Выражение**: Закрытые глаза, прямой или слегка опущенный рот
- **Использование**: Ожидание, паузы, неактивные состояния
- **Цвета**: Нейтральные серые тона

#### Стиль рисования

- **Контур**: Черный (`#000000`), толщина 2-3px
- **Заполнение**: Прозрачное или с легкой заливкой цветом эмоции
- **Форма**: Округлая, дружелюбная
- **Детали**: Минималистичные, но выразительные

#### Использование эмоций

1. **В карточках**: Для передачи настроения квиза или функции
2. **В сообщениях**: Для визуального сопровождения текстовых уведомлений
3. **В анимациях**: Для оживления интерфейса при переходах
4. **В иконках**: Как альтернатива стандартным иконкам

#### Комбинации с цветами

- **Позитивные эмоции** (радость, уверенность): Зеленые и желто-зеленые комбинации
- **Нейтральные эмоции** (задумчивость, нейтральность): Голубые и нейтральные тона
- **Негативные эмоции** (злость, скука): Коралловые и серые тона

## Эффекты и анимации

### Тени (Box Shadow)

#### Стандартная тень (кнопки, карточки)
```css
box-shadow: 
    0 6px 0px rgba(0, 0, 0, 0.3),
    0 8px 16px rgba(0, 0, 0, 0.1);
```

#### Тень при наведении
```css
box-shadow: 
    0 8px 0px rgba(0, 0, 0, 0.4),
    0 12px 24px rgba(0, 0, 0, 0.15);
```

#### Легкая тень (формы, таймер)
```css
box-shadow: 
    0 4px 0px rgba(0, 0, 0, 0.2),
    0 6px 12px rgba(0, 0, 0, 0.1);
```

#### Тень при фокусе (формы)
```css
box-shadow: 
    0 4px 0px rgba(0, 193, 89, 0.3),
    0 8px 16px rgba(0, 193, 89, 0.15);
```

### Анимации

#### fadeInUp
- **Использование**: Появление карточек снизу вверх
- **Длительность**: 0.6s
- **Easing**: ease

#### fadeInDown
- **Использование**: Появление элементов сверху вниз
- **Длительность**: 0.3s - 0.6s

#### pulse
- **Использование**: Пульсация таймера в срочном режиме
- **Длительность**: 1s
- **Easing**: ease-in-out
- **Повтор**: infinite
- **Эффект**: Масштабирование от 1 до 1.05

#### gamepadPulse
- **Использование**: Подсветка вариантов ответа при использовании джойстика
- **Длительность**: 0.3s
- **Easing**: ease
- **Эффект**: Масштабирование от 1 до 1.05

#### iconFloat
- **Использование**: Плавающая анимация иконок в карточках
- **Длительность**: 3s
- **Easing**: ease-in-out
- **Повтор**: infinite
- **Эффект**: Движение вверх-вниз с легким поворотом

#### wobble
- **Использование**: Декоративные элементы (в настоящее время отключено)
- **Эффект**: Вращение и масштабирование

### Переходы (Transitions)

#### Стандартный переход
```css
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```

#### Быстрый переход
```css
transition: all 0.2s ease;
```

#### Переход для трансформаций
```css
transition: transform 0.3s ease-in-out, opacity 0.3s ease-in-out;
```

### Трансформации

#### При наведении на кнопки/карточки
```css
transform: translateY(-6px) scale(1.02);
```

#### При активном состоянии
```css
transform: translateY(-4px) scale(0.98);
```

#### Декоративные повороты
```css
transform: rotate(-2deg);  /* Логотип, декоративные фразы */
```

### Эффекты размытия

#### Backdrop Filter
```css
backdrop-filter: blur(10px);
-webkit-backdrop-filter: blur(10px);
```
- **Использование**: Frame 4 и Frame 5 (футер)

### Градиенты

#### Радиальный градиент при наведении на карточки
```css
background: radial-gradient(circle, rgba(255, 255, 255, 0.3), transparent);
```

## Адаптивность

### Брейкпоинты

- **Mobile**: `max-width: 767px`
- **Tablet**: `768px - 1023px`
- **Desktop**: `min-width: 1024px`
- **Очень маленькие экраны**: `max-width: 480px`
- **Минимальные экраны**: `max-width: 360px`

### Принципы адаптивности

1. **Все размеры используют `clamp()`** для плавного масштабирования
2. **Минимальные размеры touch-элементов**: 44px × 44px
3. **Адаптивные отступы**: Используются vw и vh единицы для устойчивости к масштабированию
4. **Гибкая типографика**: Размеры шрифтов адаптируются к ширине экрана
5. **Симметричные отступы**: На мобильных устройствах отступы симметричны для визуального баланса
