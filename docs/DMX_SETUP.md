# DMX Система управления освещением

## 📋 Обзор

Система автоматического и ручного управления DMX освещением для квиз-платформы "ВМЕСТЕ". Поддерживает до 14 DMX фонарей над игроками и динамическое освещение сцены хоста.

## 🏗️ Архитектура

### Компоненты системы:

1. **DMX Контроллер** (`server/dmx/dmx-controller.js`)
   - Управление DMX универсумом
   - Поддержка Art-Net и USB интерфейсов
   - Режим эмуляции для разработки

2. **DMX Эффекты** (`server/dmx/dmx-effects.js`)
   - Библиотека готовых эффектов
   - Автоматические эффекты для игровых событий
   - Сценические эффекты

3. **DMX Предустановки** (`server/dmx/dmx-presets.js`)
   - Готовые сцены освещения
   - Быстрый доступ к популярным эффектам

4. **DMX Интеграция** (`server/dmx/dmx-integration.js`)
   - Автоматическая интеграция с игровыми событиями
   - Привязка фонарей к игрокам

5. **HTTP API** (`server/routes/dmx-api.js`)
   - REST API для ручного управления
   - Веб-пульт управления

```json
{
  "universe": 0,
  "interface": {

    "port": 6454
  },
  "players": {
    "count": 14,
    "startAddress": 1,

  },
  "stage": {
    "spotlights": {
      "count": 3,

    },
    "scanners": {
      "count": 1,

      "type": "MOVING_HEAD"
    },
    "effects": {
      "count": 4,
      "startAddress": 68,

      "type": "RGB"
    }
  }
}
```

### Типы интерфейсов:

1. **Art-Net** (рекомендуется)
   - Работает по сети
   - Не требует физического подключения к серверу
   - Настройка: `"type": "artnet"`, `"host"`, `"port"`

2. **USB DMX**
   - Требует физического USB интерфейса (например, Enttec Open DMX)
   - Настройка: `"type": "usb"`, `"path"` (например, `/dev/ttyUSB0`)

3. **ESP32 через MAX485** (рекомендуется для собственного решения)
   - ESP32 модуль с WiFi + MAX485 конвертер
   - Работает по WiFi, не требует физического подключения к серверу
   - Настройка: `"type": "esp32"`, `"host"` (IP адрес ESP32), `"port"` (обычно 80)
   - Подробная инструкция: см. `esp32/README.md`

## 🎛️ Структура каналов LM70S

Каждый прожектор использует 9 каналов DMX:

| Канал | Название | Диапазон | Описание |
|-------|----------|----------|----------|
| 1 | Угол по оси X | 0-255 | Угол поворота по горизонтали |
| 2 | Угол по оси Y | 0-255 | Угол поворота по вертикали |
| 3 | Режим работы | 0-8 | Свет выключен |
| | | 9-135 | Затемнение |
| | | 136-240 | Стробоскоп |
| | | 241-255 | Питание ВКЛ/ВЫКЛ |
| 4 | Затемнение КРАСНЫЙ | 0-255 | RGB - Красный канал |
| 5 | Затемнение ЗЕЛЕНЫЙ | 0-255 | RGB - Зеленый канал |
| 6 | Затемнение СИНИЙ | 0-255 | RGB - Синий канал |
| 7 | Затемнение БЕЛЫЙ | 0-255 | Белый канал |
| 8 | Скорость | 0-255 | Скорость вращения |
| 9 | Сброс настроек | 150-200 | Сброс настроек |

**Формула адреса:** Start(LM70S N) = 1 + (N - 1) × 9

**Пример:**
- LM70S #1: каналы 1-9 (DMX адреса 1-9)
- LM70S #2: каналы 10-18 (DMX адреса 10-18)
- LM70S #3: каналы 19-27 (DMX адреса 19-27)
- ... и так далее до LM70S #14 (каналы 118-126)

## 🎮 Автоматические эффекты

Система автоматически реагирует на игровые события:

| Событие | Эффект игроков | Эффект сцены |
|---------|---------------|--------------|
| Игрок подключился | Мягкое свечение синего | - |
| Игра началась | Пульсация зеленого | Яркое освещение |
| Вопрос показан | Нейтральный белый | Мягкое освещение |
| Игрок ответил | Мигание желтого | - |
| Правильный ответ | Пульсация зеленого | Вспышка зеленого |
| Неправильный ответ | Пульсация красного | Вспышка красного |
| Результаты вопроса | Подсветка по результатам | Динамические эффекты |
| Игра завершена | Радужная волна по рейтингу | Финальное шоу |

## 🌐 HTTP API

### Базовый URL: `/api/dmx`

#### GET `/api/dmx/status`
Получить статус DMX системы

#### POST `/api/dmx/player/:index`
Управление фонарем игрока

**Параметры:**
- `r`, `g`, `b` (0-255) - RGB значения
- `effect` (опционально) - эффект: `fade`, `pulse`, `flash`
- `duration` (опционально) - длительность эффекта в мс

**Пример:**
```bash
curl -X POST http://localhost:3000/api/dmx/player/0 \
  -H "Content-Type: application/json" \
  -d '{"r": 255, "g": 0, "b": 0}'
```

#### POST `/api/dmx/stage`
Управление сценой

**Параметры:**
- `action` - действие: `bright`, `soft`, `dynamic`, `final`, `flash`
- `r`, `g`, `b` (для `flash`) - RGB значения

**Пример:**
```bash
curl -X POST http://localhost:3000/api/dmx/stage \
  -H "Content-Type: application/json" \
  -d '{"action": "bright"}'
```

#### POST `/api/dmx/preset/:name`
Применить предустановку

**Доступные предустановки:**
- `all-off` - Все выключено
- `all-white` - Все белое
- `rainbow` - Радуга
- `pulse-green` - Пульсация зеленого
- `pulse-red` - Пульсация красного
- `wave-forward` - Волна вперед
- `wave-backward` - Волна назад
- `stage-bright` - Сцена яркая
- `stage-soft` - Сцена мягкая
- `stage-dynamic` - Сцена динамическая
- `final-show` - Финальное шоу

#### GET `/api/dmx/presets`
Получить список всех предустановок

#### POST `/api/dmx/effect/:name`
Запустить эффект

**Доступные эффекты:**
- `wave-players` - Волна по игрокам
- `rainbow` - Радуга

#### POST `/api/dmx/all`
Управление всеми приборами

**Параметры:**
- `action` - `off` (выключить все) или `set` (установить цвет)
- `r`, `g`, `b` (для `set`) - RGB значения

## 📦 Установка зависимостей

```bash
npm install
```

Установит следующие пакеты:
- `dmx` - библиотека для работы с DMX
- `artnet` - поддержка Art-Net протокола

## 🚀 Запуск

1. Настройте конфигурацию в `server/dmx/dmx-config.json`
2. Запустите сервер: `npm start`
3. Откройте веб-пульт: `http://localhost:3000/dmx-control.html`

## 🔌 Подключение оборудования

### Art-Net (рекомендуется):

1. Установите Art-Net ноду/конвертер (например, DMXKing eDMX1)
2. Подключите DMX приборы к ноде
3. Настройте IP адрес ноды в конфигурации
4. Убедитесь, что сервер и нода в одной сети

### USB DMX:

1. Подключите USB DMX интерфейс (например, Enttec Open DMX USB)
2. Установите драйверы
3. Определите путь к устройству (например, `/dev/ttyUSB0` на Linux)
4. Настройте путь в конфигурации

## 🎭 Режим эмуляции

Если DMX оборудование недоступно, система автоматически переходит в режим эмуляции:
- Все команды логируются в консоль
- Система работает без реального оборудования
- Можно тестировать эффекты и API
