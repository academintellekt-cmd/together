# Система централизованных конфигураций

## Обзор

Централизованная система конфигураций позволяет управлять всеми настройками проекта из одного места.

## Структура

```
/together/config/
├── system.json      # Основная конфигурация системы
└── version.json     # Информация о версии проекта
```

## Файлы конфигурации

### system.json

Основная конфигурация системы содержит:
- Настройки сети (IP диапазоны станций)
- Настройки станций (количество, пути)
- Настройки джойстика (пути к конфигурациям)
- Настройки DMX
- Настройки развертывания
- Настройки логирования
- Настройки сервера

### version.json

Информация о версии проекта:
- Номер версии
- Дата сборки
- История изменений
- Требования к совместимости

## Использование

### На сервере

```javascript
const { getConfigManager } = require('./server/utils/config-manager');
const configManager = getConfigManager();

// Получение системной конфигурации
const systemConfig = configManager.getSystemConfig();

// Получение информации о версии
const versionInfo = configManager.getVersionInfo();

// Получение конфигурации станции
const stationConfig = configManager.getStationConfig(1);

// Сохранение конфигурации станции
configManager.saveStationConfig(1, { buttons: {}, axes: {} });
```

### Через API

```bash
# Получение системной конфигурации
GET /api/config/system

# Получение информации о версии
GET /api/config/version

# Получение конфигурации джойстика станции
GET /api/local/stations/:stationNumber/joystick-config

# Сохранение конфигурации джойстика станции
POST /api/local/stations/:stationNumber/joystick-config
```

## Конфигурации станций

Конфигурации джойстиков для отдельных станций хранятся в:
```
/together/data/stations/
├── station-1.json
├── station-2.json
└── ...
```

## Преимущества

1. **Централизация** - все настройки в одном месте
2. **Версионирование** - отслеживание версий проекта
3. **Гибкость** - легко изменять настройки без изменения кода
4. **Масштабируемость** - легко добавлять новые настройки
5. **Безопасность** - контроль доступа к конфигурациям

## Миграция

Старые конфигурации продолжают работать:
- `data/joystick-config.json` - общая конфигурация джойстика
- Конфигурации в памяти станций

Новая система дополняет существующую, не ломая обратную совместимость.
