# Единая страница станции (station.html)

## Обзор

`station.html` - это единая страница для всех станций игроков, которая автоматически определяет номер станции и предоставляет все необходимые функции в одном месте.

## Архитектура

Страница построена на модульной архитектуре с использованием классов:

### Модуль 1: StationDetector
Определяет номер станции и IP адрес автоматически:
- Проверка URL параметра `?station=X`
- Определение через API `/api/local/detect-ip`
- Определение по hostname (192.168.1.21-29)
- WebRTC fallback

### Модуль 2: StationConfigManager
Управляет конфигурацией джойстика:
- Загрузка конфигурации с сервера для конкретной станции
- Сохранение конфигурации на сервер и в localStorage
- Fallback на общую конфигурацию

### Модуль 3: StationModeManager
Управляет переключением режимов:
- `waiting` - режим ожидания команд от сервера
- `joystick-setup` - режим настройки джойстика
- `game` - режим игры (переход на player.html)

### Модуль 4: StationServerConnection
Обеспечивает связь с сервером:
- Регистрация станции на сервере
- Socket.io подключение
- HTTP polling как fallback
- Обработка команд от сервера

## Использование

### Развертывание

1. Скопируйте `station.html` на все станции в папку `/together/public/`
2. Откройте `http://192.168.1.21/station.html` (или соответствующий IP станции)
3. Страница автоматически определит номер станции и подключится к серверу

### Режимы работы

#### Режим ожидания
- Станция регистрируется на сервере
- Ожидает команды от ведущего
- Показывает статус подключения

#### Режим настройки джойстика
- Загружает интерфейс настройки джойстика
- Позволяет настроить кнопки и стик
- Сохраняет конфигурацию на сервер для конкретной станции

#### Режим игры
- Автоматически открывается при получении команды от сервера
- Переходит на `player.html` с параметрами комнаты

## API

### Определение станции
```
GET /api/local/detect-ip
```

### Получение конфигурации джойстика
```
GET /api/local/stations/:stationNumber/joystick-config
```

### Сохранение конфигурации джойстика
```
POST /api/local/stations/:stationNumber/joystick-config
Body: { config: { buttons: {}, axes: {} } }
```

### Системная конфигурация
```
GET /api/config/system
GET /api/config/version
```

## Преимущества

1. **Единообразие** - один файл для всех станций
2. **Автоматическое определение** - не нужно вручную указывать номер станции
3. **Модульность** - легко добавлять новые функции
4. **Централизованная конфигурация** - все настройки на сервере
5. **Простое развертывание** - копируем один файл

## Развертывание

Все файлы проекта находятся в папке `/together`, что упрощает:
- Единообразное развертывание на всех станциях
- Простые относительные пути
- Легкое резервное копирование
- Простое обновление
