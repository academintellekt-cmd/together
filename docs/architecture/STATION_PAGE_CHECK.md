## ✅ Соответствие брендбуку

### Типографика
- ✅ Используется шрифт **Days One** для всех заголовков и статусов
- ✅ Используется шрифт **Montserrat** для основного текста (через base.css)

  - `var(--color-green)` - успешные состояния (#2fb95d)

- ✅ Правильные цвета для состояний:

  - Ожидание: темный

- ✅ Кнопки переключения режимов соответствуют стилю брендбука:

  - Скругление: `clamp(10px, 2vw, 12px)`
