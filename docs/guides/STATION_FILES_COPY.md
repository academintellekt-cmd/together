# Копирование файлов на станции

## ⚠️ ВАЖНО: Архитектура локального режима

**На станциях НЕ должен запускаться сервер!**

Станции работают как **тонкие клиенты** - они просто открывают страницы в браузере с центрального сервера.

## Структура файлов для станций

Для работы станций необходимы **только статические файлы**:

### Основные файлы:
- `public/station.html` - главная страница станции
- `public/joystick-setup.html` - страница настройки джойстика

### Связанные файлы:
- `public/styles/` - все стили
- `public/scripts/` - все скрипты
- `public/images/` - изображения

### ❌ НЕ нужны на станциях:
- `server.js` - сервер НЕ должен запускаться на станциях!
- `package.json` - зависимости не нужны (нет Node.js)
- `server/` - серверные модули не нужны
- `data/` - данные хранятся на центральном сервере
- `scripts/start.sh` - скрипты запуска не нужны

## Связь между файлами

- `station.html` загружает `joystick-setup.html` динамически при переключении в режим "Настройка джойстика"
- `joystick-setup.html` имеет ссылку "Назад" на `station.html` (скрывается при загрузке в `station.html`)
- Оба файла используют общие стили и скрипты из папки `public/`

## Варианты копирования на станции

### Вариант 1: Автоматическое развертывание (рекомендуется)

Используйте скрипты автоматического развертывания:

**Linux/Mac:**
```bash
./scripts/deploy-local.sh [USERNAME] [PASSWORD]
```

**Для одной станции:**
Используйте тот же скрипт `deploy-local.sh` - он автоматически определит доступные станции.

Скрипты автоматически:
- Создают архив **только со статическими файлами** (public/)
- Копируют на все станции (192.168.1.21 - 192.168.1.29)
- Распаковывают файлы
- **НЕ запускают сервер** (это правильно!)

### Вариант 2: Ручное копирование на Windows станции

Если станции работают на Windows и вы хотите скопировать папку на диск C:

1. **Подготовьте папку с файлами:**
   ```bash
   # Создайте архив только со статическими файлами
   tar -czf station-files.tar.gz \
       --exclude=node_modules \
       --exclude=.git \
       --exclude=server.js \
       --exclude=package.json \
       --exclude=server/ \
       --exclude=data/ \
       public/
   ```

2. **Скопируйте на каждую станцию:**
   - Распакуйте архив в `C:\together\public\` на каждой станции
   - Или скопируйте папку `public/` в `C:\together\public\`

3. **❌ НЕ устанавливайте зависимости:**
   ```powershell
   # НЕ ДЕЛАЙТЕ ЭТОГО!
   # npm install --production  ❌
   ```

4. **❌ НЕ запускайте сервер:**
   ```powershell
   # НЕ ДЕЛАЙТЕ ЭТОГО!
   # node server.js  ❌
   ```

### Вариант 3: Копирование через сеть (Windows)

Если станции доступны по сети:

1. **Откройте общий доступ к папке `public/` на главном компьютере**

2. **На каждой станции:**
   - Откройте `\\<IP_ГЛАВНОГО_КОМПЬЮТЕРА>\public`
   - Скопируйте содержимое в `C:\together\public\`

3. **Или используйте robocopy:**
   ```powershell
   robocopy \\<IP_ГЛАВНОГО>\public C:\together\public /E /Z
   ```

## Использование станций

После копирования файлов:

1. **Откройте браузер на станции**

2. **Перейдите на страницу центрального сервера:**
   ```
   http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/station.html
   ```
   Например: `http://192.168.1.10:3000/station.html`

3. **Страница автоматически:**
   - Определит номер станции
   - Подключится к центральному серверу через Socket.io
   - Будет готова к получению команд

## Проверка после копирования

После копирования файлов проверьте:

1. **Файлы на месте:**
   ```powershell
   # Windows
   Test-Path C:\together\public\station.html
   Test-Path C:\together\public\joystick-setup.html
   
   # Linux
   ls /home/pi/together/public/station.html
   ls /home/pi/together/public/joystick-setup.html
   ```

2. **Откройте страницу станции:**
   - `http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/station.html`
   - Должна открыться страница с переключателем режимов

3. **Проверьте подключение:**
   - Страница должна показать "Станция X подключена"
   - На центральном сервере откройте `local-host.html` - станция должна отображаться как подключенная

## Настройка каждой станции отдельно

Каждая станция может иметь свою конфигурацию джойстика:

1. **Откройте страницу станции:**
   ```
   http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/station.html
   ```

2. **Переключитесь в режим "Настройка джойстика"**

3. **Настройте джойстик:**
   - Калибруйте кнопки (Кнопка 1-10)
   - Калибруйте стик (Вверх, Вниз, Влево, Вправо)
   - Сохраните конфигурацию

4. **Конфигурация сохраняется:**
   - На центральном сервере в `data/joystick-config.json`
   - В localStorage браузера
   - С привязкой к номеру станции

## Важные замечания

- ✅ `station.html` и `joystick-setup.html` должны быть в папке `public/`
- ✅ Все стили и скрипты должны быть доступны
- ✅ Страницы открываются с центрального сервера
- ✅ Конфигурация джойстика сохраняется на центральном сервере
- ❌ **НЕ запускайте сервер на станциях!**
- ❌ Не копируйте файлы `server.js`, `package.json`, `server/`
- ❌ Не устанавливайте Node.js на станциях (не нужен)

## Устранение проблем

### Проблема: Страница не загружается
- Проверьте, что центральный сервер запущен и доступен
- Проверьте, что файлы скопированы в правильную папку
- Проверьте, что открываете страницу с центрального сервера, а не локально

### Проблема: Настройка джойстика не открывается
- Проверьте, что `joystick-setup.html` находится в `public/`
- Откройте консоль браузера (F12) и проверьте ошибки
- Проверьте, что все стили и скрипты загружаются

### Проблема: Конфигурация не сохраняется
- Проверьте, что центральный сервер имеет доступ к файловой системе
- Проверьте права на запись в папку `data/` на центральном сервере
- Проверьте консоль браузера на ошибки

### Проблема: Станция не подключается к серверу
- Проверьте, что центральный сервер запущен
- Проверьте, что станция и сервер в одной сети
- Проверьте, что открываете страницу с правильного IP адреса центрального сервера
