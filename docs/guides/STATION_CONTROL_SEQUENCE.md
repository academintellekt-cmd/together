# Последовательность действий для управления станциями с сервера

## Обзор системы

Система управления станциями позволяет полностью контролировать состояние и поведение страниц станций через сервер. Станции автоматически подключаются к серверу и получают команды в реальном времени через Socket.io или через HTTP polling (если Socket.io недоступен).

## Шаг 1: Запуск центрального сервера

⚠️ **ВАЖНО:** Сервер запускается **только на центральном сервере**, а НЕ на станциях!

1. **Запустите сервер на центральном сервере:**
   ```bash
   npm start
   # или
   node server.js
   ```

2. **Проверьте, что сервер запущен:**
   - Сервер должен быть доступен по адресу (например, `http://192.168.1.10:3000`)
   - В консоли должно появиться сообщение: `✅ Локальные модули доступны`
   - Сервер должен быть доступен по IP адресу, а не только localhost

## Шаг 2: Настройка станций

### Требования к станциям:

1. **IP-адреса станций:**
   - Станции должны иметь IP-адреса в диапазоне `192.168.1.21` - `192.168.1.29`
   - Каждая станция автоматически получает номер от 1 до 9 на основе последнего октета IP:
     - `192.168.1.21` → Станция №1
     - `192.168.1.22` → Станция №2
     - ...
     - `192.168.1.29` → Станция №9

2. **Сеть:**
   - Все станции должны быть в одной локальной сети с сервером
   - Сервер должен быть доступен по IP-адресу (не только localhost)

### Что нужно включить на станциях:

1. **Откройте страницу станции:**
   - На каждой станции откройте в браузере: `http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/station.html`
   - Например: `http://192.168.1.10:3000/station.html`
   - ⚠️ **ВАЖНО:** Открывайте страницу с центрального сервера, а НЕ локально!

2. **Автоматическая регистрация:**
   - Страница автоматически определит IP-адрес станции
   - Автоматически определит номер станции (1-9)
   - Автоматически зарегистрируется на сервере
   - Установит соединение через Socket.io

3. **Что происходит при открытии страницы:**
   ```
   📥 Страница загружается с центрального сервера
   🔍 Определение IP адреса станции
   📤 Отправка запроса регистрации на центральный сервер
   ✅ Регистрация успешна
   🔌 Подключение через Socket.io к центральному серверу
   📥 Получение подтверждения от сервера
   ✅ Станция готова к получению команд
   ```

4. **Если автоматическое определение не сработало:**
   - На странице появится форма для ручного ввода номера станции
   - Введите номер станции (1-9) и нажмите "Подключиться"

## Шаг 3: Управление станциями с сервера

### Вариант 1: Через интерфейс хоста (рекомендуется)

1. **Откройте страницу хоста:**
   - Откройте в браузере на центральном сервере: `http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/local-host.html`
   - Например: `http://192.168.1.10:3000/local-host.html`

2. **Проверьте подключенные станции:**
   - На странице отобразится список всех станций (1-9)
   - Подключенные станции будут отмечены зеленым цветом
   - Видно IP-адрес и статус каждой станции

3. **Выберите станции:**
   - Отметьте чекбоксами нужные станции
   - Или выберите все станции

4. **Выберите квиз:**
   - Выберите квиз из списка доступных

5. **Отправьте команду:**
   - Нажмите кнопку "Запустить квиз на выбранных станциях"
   - Станции автоматически откроют страницу игрока с выбранным квизом

### Вариант 2: Через Socket.io (программно)

```javascript
// Подключение к серверу
const socket = io('http://192.168.1.20:3000');

// Отправка команды станциям
socket.emit('local-station-command', {
  stationNumbers: [1, 2, 3], // массив номеров станций или null для всех
  command: 'navigate',
  params: {
    page: 'quiz',
    roomCode: 'ABC123',
    quizId: 'gnu'
  }
});
```

### Вариант 3: Через HTTP API

```bash
# Отправка команды через HTTP
curl -X POST http://192.168.1.20:3000/api/local/stations/command \
  -H "Content-Type: application/json" \
  -d '{
    "stationNumbers": [1, 2, 3],
    "command": "navigate",
    "params": {
      "page": "quiz",
      "roomCode": "ABC123",
      "quizId": "gnu"
    }
  }'
```

## Типы команд для управления станциями

### 1. Навигация (navigate)

**Открыть квиз:**
```javascript
socket.emit('local-station-command', {
  stationNumbers: [1, 2, 3],
  command: 'navigate',
  params: {
    page: 'quiz',
    roomCode: 'ABC123',
    quizId: 'gnu'
  }
});
```

**Вернуться в режим ожидания:**
```javascript
socket.emit('local-station-command', {
  stationNumbers: [1, 2, 3],
  command: 'navigate',
  params: {
    page: 'waiting'
  }
});
```

**Перейти на произвольную страницу:**
```javascript
socket.emit('local-station-command', {
  stationNumbers: [1],
  command: 'navigate',
  params: {
    page: 'custom',
    customUrl: '/leaderboard.html?room=ABC123'
  }
});
```

### 2. Обновление состояния (update-state)

```javascript
socket.emit('local-station-command', {
  stationNumbers: [1],
  command: 'update-state',
  params: {
    statusText: 'Игра началась',
    showTimer: true,
    timerValue: 30
  }
});
```

### 3. Обновление содержимого (update-content)

```javascript
socket.emit('local-station-command', {
  stationNumbers: [1],
  command: 'update-content',
  params: {
    selector: '#stationStatus',
    text: 'Новый статус',
    style: {
      color: '#00C159',
      fontSize: '24px'
    }
  }
});
```

### 4. Выполнение действий (execute-action)

```javascript
socket.emit('local-station-command', {
  stationNumbers: [1, 2, 3],
  command: 'execute-action',
  params: {
    action: 'showQuestion',
    data: {
      questionNumber: 1,
      questionText: 'Вопрос?'
    }
  }
});
```

### 5. Кастомные команды (custom)

```javascript
socket.emit('local-station-command', {
  stationNumbers: [1],
  command: 'custom',
  params: {
    type: 'myCustomAction',
    data: {
      customData: 'любые данные'
    }
  }
});
```

## Как станции получают команды

### Механизм доставки команд:

1. **Socket.io (приоритетный способ):**
   - Станция подключается к серверу через Socket.io при загрузке страницы
   - Команды доставляются мгновенно в реальном времени
   - Если соединение потеряно, автоматически переподключается

2. **HTTP Polling (резервный способ):**
   - Если Socket.io недоступен, станция опрашивает сервер каждые 2 секунды
   - Запрашивает команды через: `GET /api/local/stations/:stationNumber/commands`
   - Команды хранятся в очереди на сервере до получения

3. **Очередь команд:**
   - Все команды добавляются в очередь на сервере
   - Даже если станция временно отключена, команды сохраняются
   - При переподключении станция получает все накопленные команды

## Мониторинг станций

### Проверка статуса станций:

**Через HTTP API:**
```bash
# Получить статус всех станций
curl http://192.168.1.20:3000/api/local/stations/status

# Получить состояние конкретной станции
curl http://192.168.1.20:3000/api/local/stations/1/state
```

**Через Socket.io:**
```javascript
socket.on('local-stations-updated', (data) => {
  console.log('Список станций обновлен:', data.stations);
});

socket.on('local-station-status-updated', (data) => {
  console.log('Статус станции:', data);
});
```

## Отладка

### Проблемы и решения:

1. **Станция не подключается:**
   - Проверьте, что IP-адрес станции в диапазоне 192.168.1.21-29
   - Проверьте, что станция может достучаться до сервера (ping)
   - Проверьте консоль браузера на станции (F12)

2. **Команды не доходят:**
   - Проверьте консоль сервера на наличие ошибок
   - Проверьте, что станция подключена (зеленая на странице хоста)
   - Проверьте консоль браузера на станции

3. **Socket.io не работает:**
   - Система автоматически переключится на HTTP polling
   - Команды все равно будут доставлены, но с задержкой до 2 секунд

### Логи на сервере:

- `📤` - отправка команды
- `✅` - успешная отправка
- `⚠️` - предупреждение
- `❌` - ошибка
- `📥` - получение запроса от станции

### Логи на станции (консоль браузера):

- `📥` - получение команды
- `🧭` - навигация
- `🔄` - обновление состояния
- `📝` - обновление контента
- `⚡` - выполнение действия

## Резюме

**Что нужно включить на станциях:**
1. Открыть страницу `/station.html` в браузере
2. Дождаться автоматической регистрации и подключения

**Как управлять станциями:**
1. Через интерфейс хоста (`/local-host.html`) - самый простой способ
2. Через Socket.io события `local-station-command`
3. Через HTTP API `/api/local/stations/command`

**Что происходит автоматически:**
- Определение IP и номера станции
- Регистрация на сервере
- Подключение через Socket.io
- Получение команд в реальном времени
- Переключение на HTTP polling при потере соединения
- Получение накопленных команд при переподключении
