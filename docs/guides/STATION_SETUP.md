# Настройка станций для работы

## ⚠️ ВАЖНО: Архитектура локального режима

**На станциях НЕ должен запускаться сервер!**

Станции работают как **тонкие клиенты** - они просто открывают страницы в браузере с центрального сервера.

**Станции работают БЕЗ локальных файлов!** Все страницы загружаются с центрального сервера.

## Что нужно на станциях

### Минимальные требования:
1. ✅ **Браузер** (Chrome, Firefox, Edge, Safari)
2. ✅ **Сетевое подключение** к центральному серверу
3. ✅ **Статические файлы** (копируются автоматически при деплое)

### ❌ НЕ нужны на станциях:
- ❌ Node.js - НЕ нужен!
- ❌ npm - НЕ нужен!
- ❌ server.js - НЕ должен запускаться!
- ❌ PM2 - НЕ нужен!

## Шаг 2: Настройка станции

### Требования к станциям:

1. **IP-адреса станций:**
   - Станции должны иметь IP-адреса в диапазоне `192.168.1.21` - `192.168.1.29`
   - Каждая станция автоматически получает номер от 1 до 9 на основе последнего октета IP:
     - `192.168.1.21` → Станция №1
     - `192.168.1.22` → Станция №2
     - ...
     - `192.168.1.29` → Станция №9

2. **Сеть:**
   - Все станции должны быть в одной локальной сети с центральным сервером
   - Центральный сервер должен быть доступен по IP-адресу (не только localhost)

### Что нужно сделать на станции:

1. **Откройте браузер на станции**

2. **Откройте страницу с центрального сервера:**
   ```
   http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/station.html
   ```
   Например: `http://192.168.1.10:3000/station.html`
   
   ⚠️ **ВАЖНО:** Используйте `station.html`, а НЕ `local-station.html`!

3. **Автоматическая регистрация:**
   - Страница автоматически определит IP-адрес станции
   - Автоматически определит номер станции (1-9)
   - Автоматически зарегистрируется на центральном сервере
   - Установит соединение через Socket.io

4. **Что происходит при открытии страницы:**
   ```
   📥 Страница загружается с центрального сервера
   🔍 Определение IP адреса станции
   📤 Отправка запроса регистрации на центральный сервер
   ✅ Регистрация успешна
   🔌 Подключение через Socket.io к центральному серверу
   📥 Получение подтверждения от сервера
   ✅ Станция готова к получению команд
   ```

5. **Если автоматическое определение не сработало:**
   - На странице появится форма для ручного ввода номера станции
   - Введите номер станции (1-9) и нажмите "Подключиться"

## Шаг 3: Проверка работы

### Проверка на станции:

1. **Откройте страницу станции:**
   ```
   http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/station.html
   ```

2. **Проверьте статус:**
   - Должно отображаться "Станция X подключена"
   - Статус должен быть зеленым

### Проверка на центральном сервере:

1. **Откройте страницу управления:**
   ```
   http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/local-host.html
   ```

2. **Проверьте подключенные станции:**
   - На странице отобразится список всех станций (1-9)
   - Подключенные станции будут отмечены зеленым цветом
   - Видно IP-адрес и статус каждой станции

## Настройка джойстика

Каждая станция может иметь свою конфигурацию джойстика:

1. **Откройте страницу станции:**
   ```
   http://<IP_ЦЕНТРАЛЬНОГО_СЕРВЕРА>:3000/station.html
   ```

2. **Переключитесь в режим "Настройка джойстика"**

3. **Настройте джойстик:**
   - Калибруйте кнопки (Кнопка 1-10)
   - Калибруйте стик (Вверх, Вниз, Влево, Вправо)
   - Сохраните конфигурацию

4. **Конфигурация сохраняется:**
   - На центральном сервере в `data/joystick-config.json`
   - В localStorage браузера
   - С привязкой к номеру станции

## Полная настройка станции (пошагово)

### Шаг 1: Подготовка системы

```bash
# Убедитесь, что станция подключена к сети
ping 192.168.1.10  # Проверка связи с центральным сервером
```

### Шаг 2: Развертывание файлов

```bash
# На центральном сервере выполните:
./scripts/deploy-local.sh pi
```

### Шаг 3: Открытие страницы

1. На станции откройте браузер
2. Перейдите на `http://192.168.1.10:3000/station.html` (замените на IP центрального сервера)
3. Страница автоматически подключится к серверу

### Шаг 4: Проверка

1. На центральном сервере откройте `http://192.168.1.10:3000/local-host.html`
2. Проверьте, что станция отображается как подключенная (зеленым цветом)

## Устранение проблем

### Проблема: Страница не загружается
- Проверьте, что центральный сервер запущен и доступен
- Проверьте, что станция и сервер в одной сети
- Проверьте, что открываете страницу с правильного IP адреса центрального сервера
- Проверьте файрвол на станции (должен разрешать доступ к центральному серверу)

### Проблема: Станция не подключается к серверу
- Проверьте, что центральный сервер запущен
- Проверьте, что станция и сервер в одной сети
- Проверьте консоль браузера (F12) на ошибки
- Проверьте, что открываете страницу с правильного IP адреса центрального сервера

### Проблема: Станция не определяется автоматически
- Введите номер станции вручную на странице
- Или добавьте параметр в URL: `?station=1`

### Проблема: Настройка джойстика не работает
- Проверьте, что `joystick-setup.html` находится в `public/`
- Откройте консоль браузера (F12) и проверьте ошибки
- Проверьте, что все стили и скрипты загружаются

## ❌ ЧАСТЫЕ ОШИБКИ

### Ошибка 1: Запуск server.js на станции
**Неправильно:**
```bash
# На станции 192.168.1.21
cd C:\together
node server.js  # ❌ НЕ ДЕЛАЙТЕ ЭТОГО!
```

**Правильно:**
- Просто откройте браузер и перейдите на `http://192.168.1.10:3000/station.html`

### Ошибка 2: Установка Node.js на станции
**Неправильно:**
- Устанавливать Node.js на станции
- Устанавливать зависимости через npm

**Правильно:**
- На станциях нужен только браузер
- Все файлы загружаются с центрального сервера

### Ошибка 3: Открытие station.html локально
**Неправильно:**
```bash
# На станции 192.168.1.21
file:///C:/together/public/station.html  # ❌ Не сработает
http://192.168.1.21:3000/station.html  # ❌ Не сработает, если сервер не запущен
```

**Правильно:**
```bash
# На станции 192.168.1.21
http://192.168.1.10:3000/station.html  # ✅ Открыть страницу с центрального сервера
```
