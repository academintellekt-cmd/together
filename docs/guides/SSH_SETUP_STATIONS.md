# Настройка SSH для автоматического развертывания на станции

Для автоматического развертывания файлов на станции необходимо настроить SSH подключение.

## Вариант 1: SSH ключи (рекомендуется)

Это самый безопасный и удобный способ, не требует ввода пароля при каждом развертывании.

### На локальном компьютере (сервере)

1. **Проверьте наличие SSH ключа:**
   ```bash
   ls -la ~/.ssh/id_rsa.pub
   ```

2. **Если ключа нет, создайте его:**
   ```bash
   ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
   # Нажмите Enter для всех вопросов (или укажите парольную фразу)
   ```

3. **Скопируйте ключ на каждую станцию:**
   ```bash
   ssh-copy-id pi@192.168.1.21
   ssh-copy-id pi@192.168.1.22
   # ... и так далее для всех станций
   ```

4. **Проверьте подключение:**
   ```bash
   ssh pi@192.168.1.21
   # Должно подключиться без запроса пароля
   ```

### На станции (Raspberry Pi)

1. **Убедитесь, что SSH сервер запущен:**
   ```bash
   sudo systemctl status ssh
   ```

2. **Если SSH не запущен, включите его:**
   ```bash
   sudo systemctl enable ssh
   sudo systemctl start ssh
   ```

3. **Проверьте, что порт 22 открыт:**
   ```bash
   sudo ufw allow 22
   sudo ufw status
   ```

## Вариант 2: Использование пароля

Если SSH ключи не настроены, можно использовать пароль (менее безопасно).

### Требования

1. **Установите sshpass на локальном компьютере:**
   ```bash
   # macOS
   brew install hudochenkov/sshpass/sshpass
   
   # Linux
   sudo apt-get install sshpass
   ```

2. **Используйте скрипт с паролем:**
   ```bash
   ./scripts/deploy-local.sh pi raspberry
   ```

⚠️ **Внимание**: Пароль будет виден в истории команд и процессах. Используйте SSH ключи для продакшн-среды.

## Проверка подключения

### Проверка ping

```bash
ping -c 3 192.168.1.21
```

Если ping не проходит:
- Проверьте сетевое подключение
- Убедитесь, что станция включена
- Проверьте IP адрес станции

### Проверка SSH порта

```bash
# Используя nc (netcat)
nc -zv 192.168.1.21 22

# Или используя telnet
telnet 192.168.1.21 22
```

Если порт закрыт:
- Проверьте, запущен ли SSH сервер: `sudo systemctl status ssh`
- Проверьте файрвол: `sudo ufw status`
- Откройте порт: `sudo ufw allow 22`

### Проверка SSH подключения

```bash
ssh pi@192.168.1.21
```

Если подключение не работает:
- Проверьте имя пользователя (обычно `pi` для Raspberry Pi)
- Проверьте пароль
- Проверьте настройки SSH на станции: `sudo nano /etc/ssh/sshd_config`

## Устранение проблем

### Ошибка "Connection timed out"

**Причины:**
- SSH сервер не запущен на станции
- Порт 22 закрыт файрволом
- Неправильный IP адрес

**Решение:**
```bash
# На станции
sudo systemctl start ssh
sudo ufw allow 22
```

### Ошибка "Permission denied"

**Причины:**
- Неправильный пароль
- SSH ключи не настроены
- Пользователь не существует

**Решение:**
```bash
# Проверьте пользователя
ssh pi@192.168.1.21
# Если не работает, попробуйте другого пользователя или настройте SSH ключи
```

### Ошибка "Host key verification failed"

**Причины:**
- Изменился ключ хоста (например, после переустановки системы)

**Решение:**
```bash
# Удалите старый ключ из known_hosts
ssh-keygen -R 192.168.1.21
# Затем подключитесь снова
ssh pi@192.168.1.21
```

## Автоматическая настройка SSH на всех станциях

Если у вас много станций, можно автоматизировать настройку:

```bash
#!/bin/bash
# Скрипт для настройки SSH на всех станциях

STATIONS=(192.168.1.21 192.168.1.22 192.168.1.23 192.168.1.24 192.168.1.25)

for ip in "${STATIONS[@]}"; do
    echo "Настройка $ip..."
    ssh-copy-id pi@$ip
done
```

## Безопасность

### Рекомендации

1. **Используйте SSH ключи вместо паролей**
2. **Отключите вход по паролю** (после настройки ключей):
   ```bash
   # На станции
   sudo nano /etc/ssh/sshd_config
   # Установите: PasswordAuthentication no
   sudo systemctl restart ssh
   ```
3. **Используйте нестандартный порт SSH** (опционально):
   ```bash
   # На станции
   sudo nano /etc/ssh/sshd_config
   # Измените: Port 2222
   sudo systemctl restart ssh
   ```
4. **Ограничьте доступ по IP** (если возможно):
   ```bash
   # На станции
   sudo ufw allow from 192.168.1.0/24 to any port 22
   ```

## Проверка готовности к развертыванию

Перед запуском развертывания убедитесь:

- [ ] SSH сервер запущен на всех станциях
- [ ] Порт 22 открыт в файрволе
- [ ] SSH ключи скопированы на все станции (или известен пароль)
- [ ] Можно подключиться к станциям: `ssh pi@192.168.1.21`
- [ ] Станции доступны по сети: `ping 192.168.1.21`

После этого можно запускать развертывание:

```bash
./scripts/deploy-local.sh pi
```
