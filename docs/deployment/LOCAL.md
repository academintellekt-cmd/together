# 🏠 Локальный деплой (SSH)

⚠️ **ВАЖНО: Деплой локальных файлов ОТКЛЮЧЕН!**

Станции теперь работают **БЕЗ локальных файлов** - все страницы загружаются с центрального сервера.

## 📋 Архитектура

**Центральный сервер:**
- Запускает `server.js` с Node.js
- Хранит все файлы (`public/`, `server/`, `data/`)
- Хранит конфигурации джойстиков для каждой станции
- Отправляет команды станциям через Socket.io

**Станции:**
- Только браузер (Chrome, Firefox, Edge)
- Открывают страницу: `http://<IP_СЕРВЕРА>:3000/station.html`
- Автоматически определяются по IP адресу
- Получают команды от сервера
- Конфигурации джойстиков загружаются с сервера

## 📋 Информация о станции

**В данный момент используется только одна станция:**

- **IP адрес:** 192.168.1.21 (Вася)
- **URL станции:** `http://<IP_СЕРВЕРА>:3000/station.html`
- **Сеть:** Локальная сеть 192.168.1.x

> **Примечание:** Остальные станции (192.168.1.22-29) закомментированы в скрипте и не используются.

## 🚀 Настройка станций

### Шаг 1: Запуск центрального сервера

Убедитесь, что центральный сервер запущен и доступен по IP адресу:

```bash
# На центральном сервере
npm start
```

Сервер должен быть доступен по IP (не только localhost):
- Проверьте: `http://192.168.1.10:3000/station.html` (замените на IP вашего сервера)

### Шаг 2: Настройка автозапуска браузера на станции

На станции нужно настроить автоматический запуск браузера с нужной страницей.

📖 **Подробная инструкция:** [BROWSER_AUTOSTART.md](./BROWSER_AUTOSTART.md)

**Быстрый способ (Windows):**
1. Создайте ярлык браузера с параметрами:
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --app=http://192.168.1.10:3000/station.html
   ```
2. Скопируйте ярлык в папку автозагрузки (`Win+R` → `shell:startup`)

**Быстрый способ (Linux/Raspberry Pi):**
1. Создайте файл `~/.config/autostart/station.desktop`:
   ```ini
   [Desktop Entry]
   Type=Application
   Name=Station Browser
   Exec=chromium-browser --kiosk --app=http://192.168.1.10:3000/station.html
   ```

### Шаг 3: Проверка работы

1. Перезагрузите станцию
2. Браузер должен автоматически открыться
3. Страница должна загрузиться с сервера
4. Станция должна автоматически определиться и подключиться

## 📝 Что происходит при подключении станции

1. Станция открывает `http://<IP_СЕРВЕРА>:3000/station.html`
2. Страница загружается с центрального сервера
3. Автоматически определяется IP адрес станции
4. Автоматически определяется номер станции (по IP: 192.168.1.21 → станция №1)
5. Станция регистрируется на сервере через API `/api/local/register-station`
6. Устанавливается соединение через Socket.io
7. Станция получает команды от сервера (запуск квиза, переход на регистрацию и т.д.)
8. Конфигурация джойстика загружается с сервера для этой станции

## 📋 Требования

### На локальном компьютере

- Node.js и npm
- Браузер (Chrome, Firefox, Edge)

### На станциях

- Браузер (Chrome, Firefox, Edge)
- Доступ к локальной сети (192.168.1.x)
- SSH (опционально, только для настройки автозапуска на Linux)

## 🌐 Определение станции

Сервер автоматически определяет станцию по IP адресу:

- `192.168.1.21` → Станция №1
- `192.168.1.22` → Станция №2
- `192.168.1.23` → Станция №3
- ... и так далее до `192.168.1.29` → Станция №9

Если автоматическое определение не работает, можно указать номер станции в URL:
```
http://192.168.1.10:3000/station.html?station=1
```

## 🆘 Устранение неполадок

### Станция не подключается к серверу

**Проблема:** Страница не загружается или показывает ошибку подключения

**Решение:**
1. Проверьте доступность сервера: `ping 192.168.1.10` (замените на IP сервера)
2. Проверьте, что сервер запущен: `curl http://192.168.1.10:3000/station.html`
3. Убедитесь, что URL правильный в настройках автозапуска браузера
4. Проверьте настройки файрвола на сервере (порт 3000 должен быть доступен)

### Станция не определяется автоматически

**Проблема:** Станция не может определить свой номер

**Решение:**
1. Убедитесь, что IP адрес станции в диапазоне 192.168.1.21-29
2. Проверьте, что сервер доступен по IP (не только localhost)
3. Используйте параметр URL: `http://192.168.1.10:3000/station.html?station=1`

### Браузер не запускается автоматически

**Проблема:** После перезагрузки браузер не открывается

**Решение:**
1. Проверьте настройки автозапуска (см. [BROWSER_AUTOSTART.md](./BROWSER_AUTOSTART.md))
2. Убедитесь, что путь к браузеру правильный
3. Проверьте права доступа к файлам автозагрузки
4. Проверьте логи системы (Linux: `journalctl -u station-browser`)

### Конфигурация джойстика не сохраняется

**Проблема:** Настройки джойстика не сохраняются между сессиями

**Решение:**
1. Убедитесь, что станция правильно определена (проверьте номер станции)
2. Проверьте подключение к серверу (Socket.io должен быть подключен)
3. Проверьте логи сервера на наличие ошибок сохранения конфигурации
