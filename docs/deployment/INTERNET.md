Деплой приложения на внешний сервер в интернете (вместе.fun).

## 📋 Информация о сервере

- **IP адрес:** 109.107.187.189
- **Домен:** вместе.fun
- **Пользователь:** root
- **Пароль:** `t6LP6kJBE_9w663RR=Mc`
- **Путь на сервере:** `/var/www/quiz-site`

## 🚀 Команда для деплоя

```bash
./scripts/deploy.sh 109.107.187.189 root
```

При запросе пароля введите: `t6LP6kJBE_9w663RR=Mc`

## 📝 Полный процесс деплоя

### 1. Подготовка

Убедитесь, что все изменения закоммичены:

```bash
git add .
git commit -m "Описание изменений"
git push
```

### 2. Деплой

```bash
./scripts/deploy.sh 109.107.187.189 root
```

### 3. Проверка

После деплоя проверьте работу сайта:

- **HTTPS:** https://вместе.fun
- **HTTP:** http://вместе.fun
- **IP:** http://109.107.187.189:3000

## 🔧 Управление сервером

### Подключение к серверу

```bash
ssh root@109.107.187.189
```

Пароль: `t6LP6kJBE_9w663RR=Mc`

### Проверка статуса приложения

```bash
pm2 status
pm2 logs quiz-site
pm2 restart quiz-site
```

### Проверка Nginx

```bash
sudo systemctl status nginx
sudo systemctl restart nginx
sudo nginx -t
```

## 📊 Что происходит при деплое

1. Создается архив с файлами проекта (исключая локальные файлы)
2. Архив загружается на сервер через SCP
3. Создается резервная копия текущих файлов
4. Старые файлы удаляются
5. Новые файлы распаковываются
6. Устанавливаются зависимости (`npm install --production`)
7. Приложение перезапускается через PM2

## ⚠️ Важно

- Локальные файлы (`server/local/`, `public/local-*.html`) **не деплоятся** в интернет
- Документация и шрифты также исключаются из деплоя
- После деплоя приложение автоматически перезапускается

## 🆘 Устранение неполадок

### Ошибка подключения

Проверьте доступность сервера:
```bash
ping 109.107.187.189
```

### Приложение не запускается

Подключитесь к серверу и проверьте логи:
```bash
ssh root@109.107.187.189
pm2 logs quiz-site
```

### Nginx не работает

Проверьте конфигурацию:
```bash
sudo nginx -t
sudo systemctl restart nginx
```
