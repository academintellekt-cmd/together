Деплой на внешний сервер для публичного доступа через интернет.

- **Скрипт:** `./scripts/deploy.sh`
- **Сервер:** 109.107.187.189 (вместе.fun)
- **Назначение:** Публичный доступ к приложению

📖 **Подробная инструкция:** [INTERNET.md](./INTERNET.md)

## 🏠 Локальный деплой (SSH)

⚠️ **ВАЖНО: Деплой локальных файлов ОТКЛЮЧЕН!**

Станции работают **БЕЗ локальных файлов** - все страницы загружаются с центрального сервера.

- **Скрипт:** `./scripts/deploy-local.sh` (деплой закомментирован)
- **Станции:** 192.168.1.21-29
- **URL станции:** `http://<IP_СЕРВЕРА>:3000/station.html`
- **Назначение:** Настройка станций для локальных игр

📖 **Подробная инструкция:** [LOCAL.md](./LOCAL.md)  
📖 **Автозапуск браузера:** [BROWSER_AUTOSTART.md](./BROWSER_AUTOSTART.md)
