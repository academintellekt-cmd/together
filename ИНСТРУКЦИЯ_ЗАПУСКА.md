# Инструкция по запуску сервера

## Проблема: Node.js не установлен

Для работы сервера необходимо установить Node.js.

## Способы установки Node.js:

### Способ 1: Через официальный сайт (рекомендуется)
1. Откройте https://nodejs.org/
2. Скачайте LTS версию (рекомендуется)
3. Установите скачанный файл
4. Перезапустите терминал

### Способ 2: Через Homebrew (macOS)
```bash
brew install node
```

### Способ 3: Через nvm (Node Version Manager)
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc  # или ~/.zshrc
nvm install --lts
nvm use --lts
```

## После установки Node.js:

1. Установите зависимости:
```bash
cd /Users/svetlanafilipenko/Desktop/together
npm install
```

2. Запустите сервер:
```bash
npm start
```

Или используйте скрипт:
```bash
./start.sh
```

3. Откройте в браузере:
- Главная страница: http://localhost:3000/index.html
- Страница хоста: http://localhost:3000/host.html?quiz=general-knowledge
- Страница игрока: http://localhost:3000/player.html

## Проверка установки:

Проверьте, что Node.js установлен:
```bash
node --version
npm --version
```

Должны отобразиться версии Node.js и npm.
