## 🔄 Обратная совместимость

Система поддерживает старые ID для обратной совместимости:
- `friends-quiz` → автоматически создается из `gnu` для соло режима
- `gnu-multiplayer` → автоматически создается из `gnu` для мультиплеера

Но в API возвращается только основной квиз `gnu`.

## ✨ Преимущества

1. **Масштабируемость**: Для добавления нового квиза нужно только:
   - Создать `data/quizzes/{quiz-id}.json`
   - Создать `data/questions/{quiz-id}.txt`
   - Перезапустить сервер

2. **Управляемость**: Все настройки в одном месте (JSON файл)

3. **Гибкость**: Легко менять цвета, пароли, настройки без изменения кода

4. **Чистота кода**: Код отделен от данных
