# 📡 OTA Обновления через WiFi для ESP32

## ⚠️ ВАЖНО: Для первой загрузки все равно нужен USB кабель!

OTA (Over-The-Air) обновления позволяют загружать прошивку через WiFi, **НО** для первой загрузки OTA-прошивки все равно нужен рабочий USB кабель.

## 🔄 Решение проблемы с кабелем

### Вариант 1: Исправить/заменить кабель (рекомендуется)

1. **Проверьте кабель:**
   - Убедитесь, что кабель поддерживает передачу данных (не только зарядку)
   - Попробуйте другой USB кабель
   - Попробуйте другой USB порт на компьютере

2. **Проверьте драйверы:**
   - Установите драйверы CH340 или CP2102 (в зависимости от вашей платы)
   - Перезагрузите компьютер

3. **Попробуйте другой компьютер:**
   - Если есть другой компьютер с Arduino IDE, попробуйте там

### Вариант 2: Использовать OTA после первой загрузки

Если вам удастся загрузить прошивку хотя бы один раз (через другой кабель/компьютер), дальше можно обновлять через WiFi.

## 📦 Установка OTA прошивки

### Шаг 1: Загрузите базовую OTA прошивку

1. **Откройте файл `esp32/dmx-controller-ota.ino`** в Arduino IDE
2. **Настройте WiFi** (строки 23-24)
3. **Загрузите прошивку через USB кабель** (хотя бы один раз!)

### Шаг 2: Использование OTA для дальнейших обновлений

После первой загрузки:

1. **В Arduino IDE:**
   - **Tools → Port → Network Ports → [IP адрес ESP32]**
   - Или введите IP адрес вручную

2. **Нажмите Upload** - прошивка загрузится через WiFi!

## 🔧 Настройка OTA в Arduino IDE

### Способ 1: Через Network Ports

1. **Подключите ESP32 к WiFi** (должен быть загружен OTA код)
2. **В Arduino IDE:**
   - **Tools → Port → Network Ports**
   - Выберите IP адрес вашего ESP32
   - Если не видите, введите IP вручную

### Способ 2: Через esptool (командная строка)

```bash
# Узнайте IP адрес ESP32 (из Serial Monitor или веб-интерфейса)
# Например: 192.168.1.100

# Загрузите прошивку через OTA
esptool.py --chip esp32 --port socket://192.168.1.100:3232 write_flash -z 0x1000 firmware.bin
```

Но сначала нужно скомпилировать прошивку в .bin файл через Arduino IDE.

## 🎯 Пошаговая инструкция

### Если кабель не работает:

1. **Попробуйте другой кабель/порт/компьютер** для первой загрузки

2. **После успешной загрузки OTA прошивки:**
   - Запишите IP адрес ESP32 (из Serial Monitor)
   - Дальше можно обновлять через WiFi

3. **Для обновления через WiFi:**
   - Откройте `dmx-controller-ota.ino` в Arduino IDE
   - **Tools → Port → Network Ports → [IP ESP32]**
   - Нажмите Upload

## 🔒 Безопасность OTA

В коде можно установить пароль для OTA обновлений:

```cpp
const char* ota_password = "dmx123";  // Ваш пароль
```

Если оставить пустым `""`, обновления будут без пароля (небезопасно для продакшена).

## 📋 Альтернативные решения

### Если кабель точно не работает:

1. **Используйте другой компьютер** с Arduino IDE
2. **Попросите друга/коллегу** загрузить первую прошивку
3. **Купите новый USB кабель** (стоит недорого)
4. **Используйте другой ESP32** (если есть)

### Использование веб-интерфейса для обновления:

Можно добавить веб-интерфейс для загрузки прошивки через браузер, но это сложнее и требует дополнительного кода.

## 🐛 Устранение проблем OTA

### "OTA connection failed"
- ✅ Убедитесь, что ESP32 подключен к WiFi
- ✅ Проверьте, что ESP32 и компьютер в одной сети
- ✅ Проверьте IP адрес ESP32

### "OTA authentication failed"
- ✅ Проверьте пароль OTA (если установлен)
- ✅ Убедитесь, что пароль правильный в коде

### "OTA timeout"
- ✅ Убедитесь, что WiFi соединение стабильное
- ✅ Попробуйте уменьшить размер прошивки
- ✅ Перезагрузите ESP32 и попробуйте снова

## 📚 Дополнительная информация

- **OTA библиотека:** Встроена в ESP32 Arduino Core
- **Порт OTA:** По умолчанию 3232
- **Протокол:** HTTP
- **Размер прошивки:** Ограничен размером flash памяти ESP32
