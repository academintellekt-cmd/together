## 🎯 Что нужно сделать сейчас

### 1. Установить зависимости Node.js
```bash
npm install axios
```

### 2. Прошить ESP32
1. Откройте `esp32/dmx-controller.ino` в Arduino IDE
2. Установите SSID и пароль WiFi (строки 23-24)
3. Загрузите прошивку на ESP32
4. Запишите IP адрес из Serial Monitor

### 3. Настроить конфигурацию
Откройте `server/dmx/dmx-config.json` и измените:
```json
{
  "interface": {
    "type": "esp32",
    "host": "192.168.1.XXX",  // Замените на IP вашего ESP32
    "port": 80
  }
}
```

### 4. Протестировать
1. Откройте `http://[IP_ESP32]` - должен открыться веб-интерфейс
2. Запустите Node.js сервер: `npm start`
3. Откройте `http://localhost:3000/dmx-control.html`
4. Попробуйте установить цвет для игрока

## 🧪 Тестирование без DMX оборудования

По умолчанию контроллер работает в **тестовом режиме**:
- ✅ Все команды логируются в Serial Monitor
- ✅ Встроенный LED мигает при получении команд
- ✅ Веб-интерфейс показывает визуализацию каналов
- ✅ Можно тестировать все функции без реального DMX света

## 🔌 Подключение MAX485 (когда будет оборудование)

См. подробную схему в `esp32/CONNECTION_DIAGRAM.md`

**Кратко:**
- MAX485 VCC → ESP32 3.3V
- MAX485 GND → ESP32 GND
- MAX485 DI → ESP32 GPIO0
- MAX485 DE+RE → ESP32 GPIO2
- MAX485 A+ → DMX Pin 2 (Data+)
- MAX485 B- → DMX Pin 3 (Data-)
- MAX485 GND → DMX Pin 1 (GND)

После подключения измените в коде:
```cpp
#define TEST_MODE false
```

И загрузите прошивку заново.

## 🎭 Особенности

### Тестовый режим
- Визуализация всех 512 каналов DMX в веб-интерфейсе
- Логирование команд в Serial Monitor
- Индикация через встроенный LED
- Тестовые паттерны для проверки работы

### Реальный DMX режим
- Отправка DMX кадров через MAX485
- Частота обновления ~44 раза в секунду (стандарт DMX512)
- Поддержка всех 512 каналов
- Стандартный протокол DMX512

## 🐛 Если что-то не работает

1. Проверьте Serial Monitor ESP32 - там будут все ошибки
2. Проверьте веб-интерфейс ESP32 - должен открываться
3. Проверьте логи Node.js сервера
4. Убедитесь, что ESP32 и компьютер в одной WiFi сети
5. См. раздел "Устранение неполадок" в `esp32/README.md`
