# 📦 Установка и настройка ESP32 DMX Controller

## Шаг 1: Установка зависимостей Node.js

Перед использованием ESP32 контроллера необходимо установить библиотеку `axios`:

```bash
cd /Users/romanfilipenko/Documents/together
npm install axios
```

Или если вы уже в корне проекта:
```bash
npm install
```

## Шаг 2: Настройка конфигурации DMX

1. Откройте файл `server/dmx/dmx-config.json`

2. Измените тип интерфейса на `esp32`:

```json
{
  "interface": {
    "type": "esp32",
    "host": "192.168.1.100",
    "port": 80
  }
}
```

3. **Важно:** Замените `192.168.1.100` на IP адрес вашего ESP32 (увидите в Serial Monitor после прошивки)

## Шаг 3: Прошивка ESP32

См. подробную инструкцию в `esp32/README.md` или быстрый старт в `esp32/QUICK_START.md`

### Кратко:
1. Откройте `esp32/dmx-controller.ino` в Arduino IDE
2. Установите SSID и пароль WiFi (строки 23-24)
3. Выберите плату: **Tools → Board → ESP32 Arduino → ESP32 Dev Module**
4. Выберите порт: **Tools → Port → [ваш COM порт]**
5. Нажмите **Upload**
6. Откройте **Serial Monitor** (115200 baud) и запишите IP адрес

## Шаг 4: Проверка работы

### Тест 1: Веб-интерфейс ESP32
1. Откройте браузер: `http://[IP_ESP32]`
2. Должен открыться интерфейс с визуализацией каналов
3. Нажмите "✨ Тестовый паттерн" - каналы должны обновиться

### Тест 2: HTTP API ESP32
```bash
# Проверка статуса
curl http://[IP_ESP32]/api/status

# Установить канал 1 в значение 255
curl -X POST "http://[IP_ESP32]/api/channel?channel=1&value=255"

# Пакетное обновление
curl -X POST "http://[IP_ESP32]/api/batch" \
  -H "Content-Type: application/json" \
  -d '{"channels":{"1":255,"2":128,"3":64}}'
```

### Тест 3: Интеграция с Node.js
1. Запустите сервер: `npm start`
2. Откройте: `http://localhost:3000/dmx-control.html`
3. Выберите игрока и установите цвет
4. Проверьте Serial Monitor ESP32 - должны появиться команды
5. Проверьте веб-интерфейс ESP32 - каналы должны обновиться

## Шаг 5: Подключение MAX485 (когда будет DMX оборудование)

См. схему подключения в `esp32/CONNECTION_DIAGRAM.md`

### Кратко:
```
MAX485 → ESP32:
- VCC → 3.3V
- GND → GND
- DI → GPIO0
- DE+RE → GPIO2
- RO → GPIO15 (не используется)

MAX485 → DMX:
- A+ → Pin 2 (Data+)
- B- → Pin 3 (Data-)
- GND → Pin 1 (GND)
```

После подключения:
1. Откройте `esp32/dmx-controller.ino`
2. Измените: `#define TEST_MODE false`
3. Загрузите прошивку заново

## Устранение проблем

### ESP32 не подключается к WiFi
- ✅ Проверьте SSID и пароль в коде
- ✅ Убедитесь, что WiFi работает на 2.4GHz
- ✅ Проверьте, что пароль правильный (без пробелов в начале/конце)

### Node.js не может подключиться к ESP32
- ✅ Проверьте IP адрес в `dmx-config.json`
- ✅ Убедитесь, что ESP32 и компьютер в одной WiFi сети
- ✅ Проверьте файрвол на компьютере
- ✅ Попробуйте открыть веб-интерфейс ESP32 в браузере

### Команды не отправляются
- ✅ Проверьте Serial Monitor ESP32 - должны быть логи
- ✅ Проверьте веб-интерфейс ESP32 - каналы должны обновляться
- ✅ Проверьте логи Node.js сервера на наличие ошибок

### DMX не работает (когда подключено оборудование)
- ✅ Убедитесь, что `TEST_MODE = false`
- ✅ Проверьте подключение MAX485 к ESP32
- ✅ Проверьте подключение MAX485 к DMX кабелю
- ✅ Проверьте полярность A/B на DMX кабеле
- ✅ Установите терминатор 120Ω на последнем DMX устройстве
