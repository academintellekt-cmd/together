# Файлы для загрузки веб-интерфейса ESP32

Эти файлы можно загрузить на ESP32 через веб-интерфейс без перепрошивки.

## Файлы:

- **index.html** - Главная страница ESP32 DMX Controller
- **equalizer.html** - Страница эквалайзера с предустановленными командами

## Как использовать:

1. Откройте ESP32 в браузере: `http://192.168.0.172/api/files/upload-page` (или `http://esp32-dmx.local/api/files/upload-page`)

2. Перетащите файл в окно загрузки или нажмите и выберите файл

3. После загрузки страница автоматически обновится с новым интерфейсом

## Важно:

- Файлы заменят версии из прошивки
- Если файл не загружен, используется версия из прошивки (fallback)
- Для удаления файла используйте кнопку "Удалить" на странице загрузки

## Обновление файлов:

Если вы изменили код в `dmx-web-interface.h` или `dmx-equalizer-page.h`, выполните:

```bash
cd esp32/dmx-controller-ota
sed -n '5,278p' dmx-web-interface.h > upload-files/index.html
sed -n '5,375p' dmx-equalizer-page.h > upload-files/equalizer.html
```

Затем загрузите обновленные файлы через веб-интерфейс.
