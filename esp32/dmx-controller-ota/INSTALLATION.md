# 📦 Инструкция по загрузке и проверке прошивки ESP32 DMX Controller

## 🔧 Подготовка к загрузке

### 1. Установка Arduino IDE и платформы ESP32

1. Скачайте и установите [Arduino IDE](https://www.arduino.cc/en/software) (версия 1.8.x или 2.x)
2. Откройте Arduino IDE
3. Перейдите в **File → Preferences**
4. В поле "Additional Boards Manager URLs" добавьте:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
5. Перейдите в **Tools → Board → Boards Manager**
6. Найдите "esp32" и установите платформу ESP32 (версия 2.x.x или новее)

### 2. Установка необходимых библиотек

Перейдите в **Sketch → Include Library → Manage Libraries** и установите:

- **ArduinoJson** (версия 6.x) - для работы с JSON
- **WebServer** (обычно входит в ESP32 платформу)
- **ArduinoOTA** (обычно входит в ESP32 платформу)

## 📤 Загрузка прошивки

### Шаг 1: Открытие проекта

1. Откройте файл `dmx-controller-ota/dmx-controller-ota.ino` в Arduino IDE
2. Убедитесь, что файл `dmx-web-interface.h` находится в той же папке

### Шаг 2: Настройка параметров

Проверьте настройки в коде (строки 73-74):

```cpp
const char* ssid = "ELTX-2.4GHz_WiFi_D8E8";        // Название WiFi сети
const char* password = "TG22022035";                // Пароль от WiFi
```

**Статический IP уже настроен:** `192.168.0.71`

### Шаг 3: Настройка платы в Arduino IDE

1. Перейдите в **Tools → Board → ESP32 Arduino → ESP32 Dev Module**
2. Выберите правильный **Port** (COM порт, где подключен ESP32)
   - Windows: COM3, COM4 и т.д.
   - macOS/Linux: /dev/cu.usbserial-* или /dev/ttyUSB*
3. Установите параметры:
   - **Upload Speed**: 115200
   - **CPU Frequency**: 240MHz (WiFi/BT)
   - **Flash Frequency**: 80MHz
   - **Flash Size**: 4MB (32Mb)
   - **Partition Scheme**: Default 4MB with spiffs
   - **Core Debug Level**: None

### Шаг 4: Компиляция и загрузка

1. Нажмите кнопку **✓ Verify** (проверка компиляции)
   - Должно появиться "Done compiling" без ошибок
2. Подключите ESP32 к компьютеру через USB кабель
3. Нажмите кнопку **→ Upload** (загрузка)
   - Дождитесь завершения загрузки
   - В конце должно появиться "Hard resetting via RTS pin..."

## ✅ Проверка работы

### Способ 1: Через Serial Monitor (Монитор порта)

1. Откройте **Tools → Serial Monitor**
2. Установите скорость **115200 baud**
3. Нажмите кнопку **Reset** на ESP32 или перезагрузите его
4. Вы должны увидеть:

```
========================================
  ESP32 DMX Controller через MAX485
  С поддержкой OTA обновлений
========================================

[WiFi] Подключение к WiFi: ELTX-2.4GHz_WiFi_D8E8
[OK] WiFi подключен!
[WiFi] IP адрес: 192.168.0.71
[WiFi] Статический IP настроен: 192.168.0.71
[OTA] OTA обновления включены
[HTTP] HTTP сервер запущен
```

### Способ 2: Через веб-интерфейс ESP32

1. Откройте браузер
2. Перейдите по адресу: **http://192.168.0.71**
3. Должен открыться улучшенный веб-интерфейс с вкладками:
   - ⚡ Быстрое управление
   - 🎛️ Конфигуратор каналов
   - 💡 LED BAR
   - 🌫️ Туман-машина
   - 🎨 Цветовой редактор
   - 💾 Пресеты

### Способ 3: Проверка API

Откройте в браузере или через curl:

```bash
# Проверка статуса
curl http://192.168.0.71/api/dmx/status

# Должен вернуть JSON с информацией о системе
```

## 🔍 Диагностика проблем

### Проблема: ESP32 не подключается к WiFi

**Решение:**
1. Проверьте SSID и пароль в коде
2. Убедитесь, что WiFi сеть работает на частоте 2.4 GHz
3. Проверьте Serial Monitor для сообщений об ошибках

### Проблема: Не открывается веб-интерфейс

**Решение:**
1. Проверьте IP адрес в Serial Monitor
2. Убедитесь, что компьютер подключен к той же WiFi сети
3. Попробуйте пинг: `ping 192.168.0.71`
4. Проверьте, что порт 80 не заблокирован файрволом

### Проблема: Ошибки компиляции

**Решение:**
1. Убедитесь, что установлена платформа ESP32
2. Проверьте, что файл `dmx-web-interface.h` находится в той же папке
3. Убедитесь, что установлены все необходимые библиотеки

### Проблема: DMX не работает

**Решение:**
1. Проверьте подключение MAX485 к ESP32
2. Убедитесь, что TEST_MODE = false в коде
3. Проверьте подключение DMX кабеля к прожектору
4. Проверьте адрес DMX на прожекторе

## 🔄 OTA Обновления (после первой загрузки)

После первой загрузки через USB, можно обновлять прошивку через WiFi:

1. В Arduino IDE выберите **Tools → Port → esp32-dmx-controller at 192.168.0.71**
2. Загрузите прошивку как обычно - она автоматически загрузится через WiFi
3. Пароль OTA: `dmx123` (если установлен)

## 📝 Быстрая проверка функционала

1. **Проверка управления прожектором:**
   - Откройте http://192.168.0.71
   - Выберите вкладку "⚡ Быстрое управление"
   - Выберите прожектор (1-14)
   - Установите цвет RGB и нажмите "Установить цвет"

2. **Проверка конфигуратора каналов:**
   - Выберите вкладку "🎛️ Конфигуратор каналов"
   - Выберите номер прожектора (1-14)
   - Нажмите "Загрузить"
   - Должны отобразиться 9 каналов с правильными названиями:
     * Канал 1: Угол по оси X (0-255)
     * Канал 2: Угол по оси Y (0-255)
     * Канал 3: Режим работы (0-8=ВЫКЛ, 9-135=Затемнение, 136-240=Стробоскоп, 241-255=ВКЛ)
     * Канал 4: Затемнение КРАСНЫЙ (0-255) - RGB R
     * Канал 5: Затемнение ЗЕЛЕНЫЙ (0-255) - RGB G
     * Канал 6: Затемнение СИНИЙ (0-255) - RGB B
     * Канал 7: Затемнение БЕЛЫЙ (0-255)
     * Канал 8: Скорость (0-255)
     * Канал 9: Сброс настроек (150-200)

3. **Проверка LED BAR:**
   - Выберите вкладку "💡 LED BAR"
   - Выберите номер LED BAR (1-10)
   - Установите цвет и нажмите "Применить"

4. **Проверка туман-машины:**
   - Выберите вкладку "🌫️ Туман-машина"
   - Установите уровень и нажмите "Применить"
