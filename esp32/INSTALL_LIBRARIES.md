# 📚 Установка библиотек для ESP32 DMX Controller

## Ошибка: ArduinoJson.h: No such file or directory

Эта ошибка означает, что библиотека ArduinoJson не установлена в Arduino IDE.

## Решение: Установка ArduinoJson

### Способ 1: Через Library Manager (рекомендуется)

1. **Откройте Arduino IDE**

2. **Перейдите в меню:**
   - **Tools → Manage Libraries...**
   - Или нажмите **Ctrl+Shift+I** (Windows/Linux) или **Cmd+Shift+I** (Mac)

3. **В поле поиска введите:** `ArduinoJson`

4. **Найдите библиотеку:**
   - Название: **ArduinoJson**
   - Автор: **Benoit Blanchon**
   - Версия: **6.x.x** (рекомендуется версия 6)

5. **Нажмите "Install"**
   - Дождитесь завершения установки
   - Может появиться предупреждение о совместимости - это нормально, нажмите "Install All"

6. **Проверьте установку:**
   - В меню **Sketch → Include Library** должна появиться **ArduinoJson**

### Способ 2: Через GitHub (если Library Manager не работает)

1. **Скачайте библиотеку:**
   - Перейдите на: https://github.com/bblanchon/ArduinoJson/releases
   - Скачайте версию **6.x.x** (например, `ArduinoJson-6.21.3.zip`)

2. **Установите библиотеку:**
   - В Arduino IDE: **Sketch → Include Library → Add .ZIP Library...**
   - Выберите скачанный файл `.zip`
   - НЕ распаковывайте архив перед установкой!

3. **Перезапустите Arduino IDE**

## Проверка установки

После установки попробуйте скомпилировать проект снова:
- **Sketch → Verify/Compile** или **Ctrl+R** (Windows/Linux) / **Cmd+R** (Mac)

Если ошибка исчезла - библиотека установлена правильно!

## Другие необходимые библиотеки

Для ESP32 DMX Controller нужны только встроенные библиотеки:
- ✅ **WiFi** - встроенная в ESP32
- ✅ **WebServer** - встроенная в ESP32
- ✅ **ArduinoJson** - нужно установить вручную (см. выше)

## Устранение проблем

### Ошибка "Multiple libraries found"
- Arduino IDE нашел несколько версий библиотеки
- Удалите старые версии: **Sketch → Include Library → Manage Libraries** → найдите ArduinoJson → удалите старые версии

### Ошибка "Library not compatible"
- Убедитесь, что установлена версия **6.x.x** (не версия 7!)
- Версия 7 имеет другой API и не совместима с этим кодом

### Библиотека не появляется после установки
- Перезапустите Arduino IDE
- Проверьте путь установки библиотек:
  - **File → Preferences → Sketchbook location**
  - Библиотеки должны быть в папке `libraries/` внутри этой директории

## Альтернатива: Использование встроенного JSON (если библиотека не устанавливается)

Если по какой-то причине ArduinoJson не устанавливается, можно использовать простой парсинг JSON вручную, но это сложнее. Рекомендуется установить библиотеку.
