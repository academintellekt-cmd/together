## 🔧 Требования

### Оборудование:
- ESP32 модуль (любая модель с WiFi)
- MAX485 модуль (RS485 to TTL конвертер)
- Провода для подключения
- USB кабель для прошивки ESP32

### Программное обеспечение:
- Arduino IDE (версия 1.8.x или 2.x)
- ESP32 Board Support Package для Arduino IDE
- Библиотеки (устанавливаются автоматически через Arduino IDE):
  - WiFi (встроенная)
  - WebServer (встроенная)
  - ArduinoJson (нужно установить вручную)

## 🔌 Подключение оборудования

### Схема подключения MAX485 к ESP32:

```
MAX485          ESP32
─────────────────────
VCC      →      3.3V
GND      →      GND
DI       →      GPIO0  (Data In - передача данных)
RO       →      GPIO15 (Receive Out - не используется в режиме передачи)
DE+RE    →      GPIO2  (Data Enable/Receive Enable - управление направлением)
```

### Подключение MAX485 к DMX:

```
MAX485          DMX устройство/кабель
─────────────────────────────────────
A (A+)  →      DMX Data+ (Pin 2)
B (B-)  →      DMX Data- (Pin 3)
GND     →      DMX GND (Pin 1)
```

**Важно:**
- Убедитесь, что MAX485 подключен к правильным пинам ESP32
- Проверьте полярность подключения A/B к DMX кабелю
- Для длинных кабелей используйте терминатор 120Ω на последнем устройстве

## 📦 Установка и настройка

### 1. Установка Arduino IDE

1. Скачайте Arduino IDE с [официального сайта](https://www.arduino.cc/en/software)
2. Установите Arduino IDE на ваш компьютер

### 2. Установка поддержки ESP32 в Arduino IDE

1. Откройте Arduino IDE
2. Перейдите в **File → Preferences**
3. В поле **Additional Board Manager URLs** добавьте:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
4. Нажмите **OK**
5. Перейдите в **Tools → Board → Boards Manager**
6. Найдите **esp32** и нажмите **Install**
7. Дождитесь завершения установки

### 3. Установка библиотеки ArduinoJson

**⚠️ ВАЖНО: Эта библиотека обязательна для работы проекта!**

1. В Arduino IDE перейдите в **Tools → Manage Libraries**
2. Найдите **ArduinoJson** (автор: Benoit Blanchon)
3. Установите версию **6.x** (рекомендуется, НЕ версию 7!)
4. Нажмите **Install**

**Если возникли проблемы с установкой, см. подробную инструкцию:** `esp32/INSTALL_LIBRARIES.md`

### 4. Настройка проекта

1. Откройте файл `dmx-controller.ino` в Arduino IDE
2. Найдите строки с настройками WiFi (около строки 20):
   ```cpp
   const char* ssid = "YOUR_WIFI_SSID";
   const char* password = "YOUR_WIFI_PASSWORD";
   ```
3. Замените на ваши данные WiFi
4. При необходимости измените режим тестирования:
   ```cpp
   #define TEST_MODE true  // true = тестовый режим, false = реальный DMX
   ```

## 💾 Прошивка ESP32

### Шаг 1: Подключение ESP32

1. Подключите ESP32 к компьютеру через USB кабель
2. Определите COM порт:
   - **Windows**: Диспетчер устройств → Порты (COM и LPT)
   - **macOS**: `/dev/cu.usbserial-*` или `/dev/cu.SLAB_USBtoUART`
   - **Linux**: `/dev/ttyUSB0` или `/dev/ttyACM0`

### Шаг 2: Настройка Arduino IDE

1. В Arduino IDE выберите плату:
   - **Tools → Board → ESP32 Arduino → ESP32 Dev Module** (или ваша модель)
2. Выберите COM порт:
   - **Tools → Port → [ваш COM порт]**
3. Настройте параметры (если нужно):
   - **Upload Speed**: 115200
   - **CPU Frequency**: 240MHz
   - **Flash Frequency**: 80MHz
   - **Flash Mode**: QIO
   - **Flash Size**: 4MB (или больше, если у вас больше)

### Шаг 3: Загрузка прошивки

1. Нажмите кнопку **Upload** (стрелка вправо) или **Ctrl+U**
2. Дождитесь компиляции (может занять 1-2 минуты при первом запуске)
3. Если появится сообщение "Connecting....", нажмите и удерживайте кнопку **BOOT** на ESP32
4. Дождитесь завершения загрузки
5. Откройте **Serial Monitor** (Tools → Serial Monitor) со скоростью **115200 baud**

### Шаг 4: Проверка работы

После загрузки в Serial Monitor вы должны увидеть:
```
╔══════════════════════════════════════╗
║   ESP32 DMX Controller через MAX485  ║
╚══════════════════════════════════════╝

✅ DMX инициализирован
📡 Подключение к WiFi: [ваш SSID]
...
✅ WiFi подключен!
📱 IP адрес: 192.168.1.XXX
🌐 HTTP сервер запущен
```

**Запишите IP адрес** - он понадобится для настройки Node.js сервера!

## 🧪 Тестирование

### Режим тестирования (без реального DMX оборудования)

По умолчанию контроллер работает в **тестовом режиме**. Это означает:
- ✅ Все команды логируются в Serial Monitor
- ✅ Встроенный LED мигает при получении команд
- ✅ Доступен веб-интерфейс для визуализации состояния каналов

### Веб-интерфейс для тестирования

1. Откройте браузер
2. Перейдите по адресу: `http://[IP_ESP32]`
   Например: `http://192.168.1.100`
3. Вы увидите интерфейс с визуализацией каналов DMX
4. Каналы отображаются в виде карточек с значениями и прогресс-барами
5. Можно тестировать команды через кнопки

### Тестирование через Serial Monitor

В Serial Monitor вы увидите все команды DMX:
```
📤 DMX: Channel 1 = 255
📤 DMX: Channel 2 = 128
📤 DMX Batch: Обновлено 42 каналов
```

### Тестирование через HTTP API

Вы можете отправлять команды напрямую через HTTP:

```bash
# Установить канал 1 в значение 255
curl -X POST "http://192.168.1.100/api/channel?channel=1&value=255"

# Пакетное обновление каналов
curl -X POST "http://192.168.1.100/api/batch" \
  -H "Content-Type: application/json" \
  -d '{"channels":{"1":255,"2":128,"3":64}}'

# Выключить все каналы
curl -X POST "http://192.168.1.100/api/all" \
  -H "Content-Type: application/json" \
  -d '{"action":"off"}'

# Тестовый паттерн
curl -X POST "http://192.168.1.100/api/test"
```

### Переход на реальный DMX

Когда будет готово DMX оборудование:

1. Откройте `dmx-controller.ino`
2. Измените:
   ```cpp
   #define TEST_MODE false
   ```
3. Загрузите прошивку заново
4. Подключите MAX485 к DMX кабелю
5. Проверьте работу с реальным оборудованием

## 🔗 Интеграция с Node.js сервером

### 1. Обновление конфигурации DMX

Откройте файл `server/dmx/dmx-config.json` и измените:

```json
{
  "interface": {
    "type": "esp32",
    "host": "192.168.1.100",
    "port": 80
  }
}
```

Замените `192.168.1.100` на IP адрес вашего ESP32.

### 2. Проверка работы

1. Запустите Node.js сервер: `npm start`
2. Откройте веб-интерфейс: `http://localhost:3000/dmx-control.html`
3. Попробуйте установить цвет для игрока
4. Проверьте Serial Monitor ESP32 - должны появиться команды
5. Проверьте веб-интерфейс ESP32 - каналы должны обновиться

## 🐛 Устранение неполадок

### ESP32 не подключается к WiFi

- ✅ Проверьте SSID и пароль в коде
- ✅ Убедитесь, что WiFi работает на частоте 2.4GHz (ESP32 не поддерживает 5GHz)
- ✅ Проверьте, что пароль правильный (без лишних пробелов)
- ✅ Попробуйте перезагрузить ESP32

### Не видно IP адрес в Serial Monitor

- ✅ Убедитесь, что скорость Serial Monitor = 115200 baud
- ✅ Нажмите кнопку RESET на ESP32
- ✅ Проверьте подключение USB кабеля

### HTTP запросы не работают

- ✅ Проверьте, что ESP32 и компьютер в одной WiFi сети
- ✅ Проверьте IP адрес ESP32 (может измениться после перезагрузки)
- ✅ Попробуйте открыть веб-интерфейс ESP32 в браузере
- ✅ Проверьте файрвол на компьютере

### DMX команды не отправляются

- ✅ Проверьте подключение MAX485 к ESP32
- ✅ Убедитесь, что `TEST_MODE = false` для реального DMX
- ✅ Проверьте подключение MAX485 к DMX кабелю
- ✅ Проверьте полярность A/B на DMX кабеле
- ✅ Убедитесь, что на последнем DMX устройстве установлен терминатор 120Ω

### Ошибки компиляции в Arduino IDE

- ✅ Убедитесь, что установлена поддержка ESP32
- ✅ Проверьте, что установлена библиотека ArduinoJson
- ✅ Попробуйте перезапустить Arduino IDE
- ✅ Обновите ESP32 Board Support Package до последней версии

### ESP32 не загружается (зависает на "Connecting...")

- ✅ Нажмите и удерживайте кнопку **BOOT** на ESP32 во время загрузки
- ✅ Попробуйте другой USB кабель (должен поддерживать передачу данных)
- ✅ Попробуйте другой USB порт
- ✅ Проверьте драйверы USB-to-Serial для вашей платы ESP32

## 📚 Дополнительная информация

### API Endpoints ESP32

- `GET /` - Веб-интерфейс для визуализации
- `GET /api/status` - Статус контроллера
- `GET /api/channels` - Получить все каналы DMX
- `POST /api/channel?channel=X&value=Y` - Установить значение канала
- `POST /api/batch` - Пакетное обновление каналов (JSON)
- `POST /api/all` - Управление всеми каналами
- `POST /api/test` - Тестовый паттерн

### Формат пакетного обновления

```json
{
  "channels": {
    "1": 255,
    "2": 128,
    "3": 64
  }
}
```

### Частота обновления DMX

Контроллер отправляет DMX кадры с частотой ~44 раза в секунду (стандарт DMX512).
