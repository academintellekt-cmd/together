# Дизайн-система проекта

## Общая концепция

Дизайн вдохновлен минималистичным стилем Apple с фокусом на:
- **Простоту** — чистый интерфейс без перегруженности
- **Читаемость** — четкая типографика и контрастность
- **Плавность** — деликатные переходы без навязчивых анимаций
- **Современность** — актуальные тренды 2024-2025

## Цветовая палитра

### Основные цвета
- **Primary**: `#007AFF` — синий акцент (кнопки, ссылки)
- **Success**: `#34C759` — зеленый (правильные ответы, готовность)
- **Warning**: `#FF9500` — оранжевый (ожидание, процесс)
- **Error**: `#FF3B30` — красный (ошибки, неправильные ответы)

### Градиенты
- **Фон**: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
- Мягкие, не отвлекающие от контента

### Прозрачность
Все элементы используют `rgba` с прозрачностью для создания эффекта "глубины":
- Карточки: `rgba(255, 255, 255, 0.08)`
- Кнопки: `rgba(255, 255, 255, 0.15)`
- Бордеры: `rgba(255, 255, 255, 0.12)`

## Типографика

### Шрифты
```css
font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
```

### Размеры
- **H1**: 48px (заголовки страниц)
- **H2**: 36px (секции)
- **H3**: 24px (подзаголовки)
- **Body**: 17px (основной текст)
- **Small**: 15px (вспомогательный текст)

### Веса
- **Light**: 300 (таймеры, крупные числа)
- **Regular**: 400 (основной текст)
- **Medium**: 500 (кнопки, важный текст)
- **Semibold**: 600 (заголовки)
- **Bold**: 700 (акценты)

## Компоненты

### Кнопки
```css
/* Основная кнопка */
padding: 14px 32px;
border-radius: 12px;
background: rgba(255, 255, 255, 0.15);
border: 1px solid rgba(255, 255, 255, 0.2);
```

**Состояния:**
- Hover: легкое поднятие (`translateY(-1px)`)
- Active: возврат
- Disabled: прозрачность 50%

### Карточки
```css
border-radius: 16-24px;
backdrop-filter: blur(20px) saturate(180%);
box-shadow: 0 10px 15px -3px rgba(0, 0, 0, 0.1);
```

### Формы
- Скругленные углы: `12px`
- Padding: `14px 16px`
- Фокус: увеличение прозрачности фона

### HUB (верхняя панель)
- Фиксированная позиция
- Backdrop blur для "стеклянного" эффекта
- Минималистичное отображение игроков
- Статусы через эмодзи (✓, ?, ⏳)

## Анимации

### Принципы
- **Минимализм** — только необходимые анимации
- **Скорость** — 0.2-0.3s для большинства переходов
- **Easing** — `cubic-bezier(0.4, 0, 0.2, 1)` для плавности

### Основные переходы
```css
transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
```

### Удалены
- Избыточные `fadeIn`, `slideIn` анимации
- Сложные transform эффекты
- Pulse анимации (кроме таймера)

## Эффекты

### Glassmorphism (стеклянный эффект)
```css
backdrop-filter: blur(20px) saturate(180%);
-webkit-backdrop-filter: blur(20px) saturate(180%);
background: rgba(255, 255, 255, 0.08);
border: 1px solid rgba(255, 255, 255, 0.18);
```

### Тени
Используем CSS переменные для консистентности:
- `--shadow-sm`: легкая тень
- `--shadow-md`: средняя тень
- `--shadow-lg`: крупная тень
- `--shadow-xl`: очень крупная тень

## Адаптивность

### Breakpoints
- **Desktop**: > 768px
- **Tablet**: 481-768px
- **Mobile**: ≤ 480px

### Изменения на мобильных
- Меньше padding
- Упрощенные размеры шрифтов
- Одноколоночная сетка
- Компактный HUB

## Лучшие практики

### DO ✅
- Использовать CSS переменные
- Поддерживать контрастность
- Тестировать на разных устройствах
- Следовать установленным отступам
- Использовать относительные единицы (em, rem)

### DON'T ❌
- Добавлять избыточные анимации
- Использовать жесткие цвета
- Создавать новые стили вне системы
- Игнорировать мобильную адаптацию
- Смешивать разные стили кнопок

## Доступность

- Минимальная контрастность: 4.5:1
- Фокус-состояния для всех интерактивных элементов
- Семантический HTML
- Поддержка навигации с клавиатуры
