# Проверка подключения ESP32

## Текущая ситуация

- IP адрес в конфигурации: `192.168.0.172`
- Устройство найдено в ARP таблице (MAC: 28-56-2f-4a-48-4c)
- Но HTTP запросы не проходят

## Возможные причины и решения

### 1. ESP32 не подключен к WiFi

**Проверка:**
- Посмотрите на ESP32 - должен мигать светодиод (если есть)
- Проверьте Serial Monitor в Arduino IDE - должен показывать IP адрес при подключении

**Решение:**
- Перезагрузите ESP32
- Проверьте настройки WiFi в прошивке (строки 87-88 в `dmx-controller-ota.ino`)

### 2. ESP32 получил новый IP адрес

**Проверка:**
- Откройте веб-интерфейс роутера
- Найдите устройство с MAC адресом `28-56-2f-4a-48-4c`
- Проверьте назначенный IP адрес

**Решение:**
- Обновите IP в `server/dmx/dmx-config.json`
- Или настройте статический IP на роутере для ESP32

### 3. ESP32 в режиме точки доступа (AP)

Если ESP32 не может подключиться к WiFi, он может создать свою точку доступа.

**Проверка:**
- Найдите WiFi сеть с названием типа "ESP32-DMX" или похожим
- Подключитесь к ней
- Откройте `http://192.168.4.1` в браузере

### 4. Проблема с портом 80

**Проверка:**
- Попробуйте открыть `http://192.168.0.172` в браузере (без `/api/dmx/status`)
- Должна открыться веб-страница ESP32

**Решение:**
- Если порт другой, обновите `port` в конфигурации

## Как найти ESP32

### Способ 1: Через роутер
1. Откройте веб-интерфейс роутера (обычно `192.168.0.1` или `192.168.1.1`)
2. Найдите раздел "Подключенные устройства" или "DHCP клиенты"
3. Найдите устройство с MAC `28-56-2f-4a-48-4c`
4. Посмотрите назначенный IP адрес

### Способ 2: Через Serial Monitor
1. Подключите ESP32 к компьютеру через USB
2. Откройте Arduino IDE
3. Откройте Serial Monitor (Ctrl+Shift+M)
4. Установите скорость 115200
5. Перезагрузите ESP32
6. В логах должен быть IP адрес

### Способ 3: Сканирование сети
Запустите скрипт `find-esp32.ps1`:
```powershell
.\find-esp32.ps1
```

## Быстрое решение

Если нужно быстро найти ESP32:

1. **Проверьте веб-интерфейс роутера** - самый быстрый способ
2. **Используйте Serial Monitor** - если ESP32 подключен через USB
3. **Попробуйте подключиться к точке доступа ESP32** - если он не может подключиться к WiFi

## После нахождения правильного IP

Обновите `server/dmx/dmx-config.json`:
```json
{
  "interface": {
    "type": "esp32",
    "host": "НОВЫЙ_IP_АДРЕС",
    "port": 80
  }
}
```

И перезапустите сервер.
