# 🎮 Квиз-платформа "ВМЕСТЕ"

Онлайн-квиз с механикой party games, где главный экран работает в браузере на ПК/ТВ, а игроки подключаются со смартфонов.

## 🚀 Быстрый запуск

### 1. Установите Node.js (если еще не установлен)

**Способ 1 (рекомендуется):**
- Откройте https://nodejs.org/
- Скачайте LTS версию для вашей ОС
- Установите скачанный файл

**Способ 2 (через Homebrew на macOS):**
```bash
brew install node
```

### 2. Запустите сервер

```bash
./start.sh
```

Или вручную:
```bash
npm install  # первый раз
npm start
```

### 3. Откройте в браузере

- **Главная**: http://localhost:3000/
- **Хост (мультиплеер)**: http://localhost:3000/host.html
- **Игроки**: http://localhost:3000/player.html
- **Одиночная игра**: http://localhost:3000/solo.html

⚠️ **ВАЖНО**: Открывайте через `http://localhost:3000/`, а НЕ через `file://`!

## 📋 Требования

- Node.js 14+ (скачайте с https://nodejs.org/)
- npm (устанавливается вместе с Node.js)

## 🎮 Как играть

### Мультиплеер

1. **Хост (ведущий)**:
   - Откройте http://localhost:3000/host.html
   - Выберите квиз и создайте комнату
   - Скопируйте код комнаты или отсканируйте QR-код
   - Дождитесь подключения игроков (до 14 человек)
   - Нажмите "Начать игру"

2. **Игроки**:
   - Откройте http://localhost:3000/player.html на смартфоне
   - Введите код комнаты (или отсканируйте QR-код)
   - Введите свое имя
   - Нажмите "Подключиться"
   - Отвечайте на вопросы!

### Одиночная игра

1. Откройте http://localhost:3000/solo.html
2. Выберите квиз
3. Начните игру
4. Отвечайте на вопросы и соревнуйтесь с другими игроками в рейтинге!

## 🔧 Решение проблем

**Порт занят:**
```bash
PORT=3001 npm start
```

**Node.js не найден:**
Установите Node.js с https://nodejs.org/ (LTS версия)

**Зависимости не устанавливаются:**
```bash
rm -rf node_modules package-lock.json
npm install
```

## 📊 Параметры игры

- Максимум игроков: 14
- Количество вопросов: настраивается для каждого квиза
- Время на ответ: настраивается для каждого вопроса
- Варианты ответов: 4
- Задержка после ответа: 0.75 секунды

## 💯 Система очков

- Правильный ответ: 100 очков
- Бонус за скорость: дополнительные очки в зависимости от времени ответа
- Рейтинг сохраняется в Google Sheets
