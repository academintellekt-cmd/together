# 🎮 Квиз на основе механики Party Games

Онлайн-квиз с механикой, аналогичной форматам PSTV / PARTYstation, где главный экран работает в браузере на ПК/ТВ, а игроки подключаются со смартфонов.

## 🚀 Быстрый запуск

### 1. Установите Node.js (если еще не установлен)

**Способ 1 (рекомендуется):**
- Откройте https://nodejs.org/
- Скачайте LTS версию для macOS
- Установите скачанный файл

**Способ 2 (через Homebrew):**
```bash
brew install node
```

### 2. Запустите сервер

```bash
./start.sh
```

Или вручную:
```bash
npm install  # первый раз
npm start
```

### 3. Откройте в браузере

- **Хост**: http://localhost:3000/host.html
- **Игроки**: http://localhost:3000/player.html

⚠️ **ВАЖНО**: Открывайте через `http://localhost:3000/`, а НЕ через `file://`!

## 📋 Требования

- Node.js 14+ (скачайте с https://nodejs.org/)
- npm (устанавливается вместе с Node.js)

## 🌐 Деплой в интернет

Это приложение можно задеплоить в интернет через:

- **Railway** - альтернативный вариант

**GitHub Pages не поддерживает Node.js**, поэтому нужен другой хостинг.

📖 **Подробные инструкции по деплою:** см. [DEPLOY_INSTRUCTIONS.md](./DEPLOY_INSTRUCTIONS.md)

## 🎮 Как играть

1. **Хост (ведущий)**:
   - Запустите сервер: `npm start`
   - Откройте http://localhost:3000/host.html
   - Скопируйте код комнаты или отсканируйте QR-код
   - Дождитесь подключения игроков (до 14 человек)
   - Нажмите "Начать игру"

2. **Игроки**:
   - Откройте http://localhost:3000/player.html на смартфоне
   - Введите код комнаты (или отсканируйте QR-код)
   - Введите свое имя
   - Нажмите "Подключиться"
   - Отвечайте на вопросы!

## 🔧 Решение проблем

**Порт занят:**
```bash
PORT=3001 npm start
```

**Node.js не найден:**
Установите Node.js с https://nodejs.org/ (LTS версия)

**Зависимости не устанавливаются:**
```bash
rm -rf node_modules package-lock.json
npm install
```

## 📊 Параметры игры

- Максимум игроков: 14
- Количество вопросов: 10
- Время на ответ: 10-45 секунд
- Варианты ответов: 4

## 💯 Система очков

- Правильный ответ: 100 очков
- Бонус за скорость: дополнительные очки в зависимости от времени ответа
