Техническое задание для дизайнера
Оформление интерфейса / кнопок / рамок в стиле Time Quest Lab

1. Основные цвета (строго из брендбука)
Тёмный фон (база):
- #0B0B0C — глубокий графитовый/чёрный фон

Фирменные цвета:
1. Голубой — PANTONE 317C — HEX #ABE5F1
2. Зелёный — PANTONE 372C — HEX #CAF58D
3. Жёлтый — PANTONE 1225C — HEX #FDC248
4. Оранжевый — PANTONE 1595C — HEX #E55B18

2. Общий стиль интерфейса (UX/UI)
- Неоновые контуры, лёгкое свечение
- Толщина линий 2–3 px
- Прямые углы, радиус до 6 px
- Плоскостной минимализм без 3D

3. Кнопки
Основная CTA-кнопка:
- Цвет: жёлтый #FDC248
- Голубая рамка #ABE5F1
- Лёгкое свечение
Вторичная кнопка:
- Цвет: оранжевый #E55B18
- Жёлтая/голубая рамка
Неактивная:
- Прозрачная
- Голубая рамка с прозрачностью 30%

4. Рамки / карточки
- Тёмный фон
- Голубой контур 2 px
- Внутренние разделители — зелёные
- Лёгкая неоновая подсветка

5. Иконки
- Плоские, контурные, 2 px
- Цвет: голубой (основной), зелёный/оранжевый — статусные
- Лёгкий glow допустим

6. Фон
- #0B0B0C
- Возможно: мягкие неоновые разводы 5% opacity
- Тонкие технологичные линии/сетки

7. Текст и типографика
- Белый #FFFFFF
- Голубой #ABE5F1 — вторичный текст
- Зелёный #CAF58D — подписи
- Без теней, максимальный контраст

8. Примеры визуальной композиции
— Основная кнопка: тёмный фон → жёлтая заливка → голубая рамка.
— Карточка: тёмный фон → голубая рамка → зелёные подзаголовки.
— Ошибка: оранжевая кнопка → белый текст.

9. Ограничения
- Без новых цветов
- Без градиентов в кнопках
- Без скевоморфизма
- Без теней с размытием

10. Что дизайнер должен выдать
1. 3 варианта кнопок
2. 4 вида карточек
3. Панель навигации
4. 10 иконок
5. 1 общий UI-экран

Все элементы должны выглядеть как часть технологичной вселенной Time Quest Lab.
