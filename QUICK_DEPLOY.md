# Быстрое развертывание квиз-сайта

## 🚀 Автоматическое развертывание (рекомендуется)

```bash
# Замените YOUR_SERVER_IP на IP вашего сервера
./deploy.sh YOUR_SERVER_IP root
```

Пример:
```bash
./deploy.sh 192.168.1.100 root
```

## 📋 Что делает скрипт автоматически:

1. ✅ Создает архив с файлами проекта
2. ✅ Загружает файлы на сервер
3. ✅ Устанавливает Node.js и PM2
4. ✅ Устанавливает зависимости проекта
5. ✅ Настраивает файрвол (порт 3000)
6. ✅ Запускает приложение с PM2
7. ✅ Настраивает автозапуск при перезагрузке

## 🌐 После развертывания

Ваш сайт будет доступен по адресам:
- **Главная:** http://YOUR_SERVER_IP:3000/
- **Хост игры:** http://YOUR_SERVER_IP:3000/host.html  
- **Игроки:** http://YOUR_SERVER_IP:3000/player.html

## 📊 Управление сервером

Подключитесь к серверу:
```bash
ssh root@YOUR_SERVER_IP
```

Полезные команды:
```bash
pm2 status          # Статус приложения
pm2 logs quiz-site   # Просмотр логов
pm2 restart quiz-site # Перезапуск
pm2 stop quiz-site   # Остановка
pm2 monit           # Мониторинг в реальном времени
```

## 🔄 Обновление сайта

Для обновления просто запустите скрипт заново:
```bash
./deploy.sh YOUR_SERVER_IP root
```

## ⚠️ Требования

- Ubuntu/Debian сервер
- SSH доступ с правами root
- Открытый порт 3000

## 🆘 Если что-то пошло не так

1. Проверьте SSH подключение:
   ```bash
   ssh root@YOUR_SERVER_IP
   ```

2. Проверьте статус на сервере:
   ```bash
   pm2 status
   pm2 logs quiz-site
   ```

3. Проверьте порт:
   ```bash
   netstat -tlnp | grep 3000
   ```
