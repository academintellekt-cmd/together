ℹ️ Инструкция:
• Главная страница - быстрое управление игроками, каналами, LED BAR, туманом и цветами
• Эквалайзер - детальное управление каналами LM70S с предустановленными командами с сервера
• Загрузка файлов - обновите HTML интерфейс без перепрошивки ESP32 (drag & drop файлы)
• Настройка WiFi - подключение ESP32 к вашей WiFi сети
• OTA обновления - обновление прошивки ESP32 через WiFi (используйте Arduino IDE или esptool)
• Веб-пульт - полнофункциональное управление с сервера Node.js на порту 3000
