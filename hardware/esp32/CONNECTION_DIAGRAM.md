# 🔌 Схема подключения ESP32 + MAX485

## Подключение MAX485 к ESP32

```
┌─────────────┐         ┌──────────────┐
│    ESP32    │         │    MAX485    │
├─────────────┤         ├──────────────┤
│             │         │              │
│ 3.3V    ───┼─────────┼─> VCC        │
│ GND     ───┼─────────┼─> GND        │
│ GPIO12  ───┼─────────┼─> DI         │ (Data In)
│ GPIO14  ───┼─────────┼─> DE+RE      │ (Data Enable/Receive Enable)
│ GPIO27  ───┼─────────┼─> RO         │ (Receive Out - не используется)
│             │         │              │
└─────────────┘         └──────────────┘
```

## Подключение MAX485 к DMX кабелю (XLR-3)

**ВАЖНО:** Проверьте маркировку вашего кабеля! Некоторые кабели могут иметь инвертированную полярность.

### Стандартное подключение DMX512:
```
┌──────────────┐         ┌──────────────┐
│    MAX485    │         │   XLR-3      │
├──────────────┤         ├──────────────┤
│              │         │              │
│ A (A+)   ───┼─────────┼─> Pin 2 (Data+ / Signal+)│
│ B (B-)   ───┼─────────┼─> Pin 3 (Data- / Signal-)│
│ GND      ───┼─────────┼─> Pin 1 (GND / Shield) │
│              │         │              │
└──────────────┘         └──────────────┘
```

### Если цвета не меняются - попробуйте поменять местами A и B:
```
┌──────────────┐         ┌──────────────┐
│    MAX485    │         │   XLR-3      │
├──────────────┤         ├──────────────┤
│              │         │              │
│ A (A+)   ───┼─────────┼─> Pin 3 (Data+ / Signal+)│
│ B (B-)   ───┼─────────┼─> Pin 2 (Data- / Signal-)│
│ GND      ───┼─────────┼─> Pin 1 (GND / Shield) │
│              │         │              │
└──────────────┘         └──────────────┘
```

**Примечание:** Если на вашем кабеле Pin 2 = Data- и Pin 3 = Data+, используйте вторую схему (поменяйте A и B местами).

## Важные замечания

### Полярность DMX кабеля (XLR-3)
**Стандарт DMX512:**
- **A+ (Data+)** → **Pin 2** (Data+ / Signal+)
- **B- (Data-)** → **Pin 3** (Data- / Signal-)
- **GND** → **Pin 1** (GND / Shield)

**ВАЖНО:** Если цвета не меняются, попробуйте поменять местами A и B на MAX485!
Некоторые кабели или устройства могут иметь инвертированную полярность.

### Терминатор
Для длинных DMX кабелей (>100 метров) или при проблемах со стабильностью:
- Установите терминатор **120Ω** между Pin 2 и Pin 3 на **последнем** DMX устройстве в цепи

### Питание MAX485
- MAX485 должен питаться от **3.3V** (не 5V!)
- ESP32 выдает 3.3V на выводе VCC
- Проверьте, что ваш MAX485 модуль работает от 3.3V

### Альтернативные пины ESP32
Если GPIO12 не работает:
- Можно использовать **GPIO17** для TX (измените `DMX_TX_PIN` в коде и используйте Serial2)
- Или **GPIO16** (но проверьте документацию вашей платы ESP32)

## Проверка подключения

1. **Проверьте питание MAX485:**
   - LED на модуле должен гореть (если есть)

2. **Проверьте подключение к ESP32:**
   - Используйте мультиметр для проверки соединений
   - Убедитесь, что нет коротких замыканий

3. **Проверьте DMX кабель:**
   - Используйте тестер DMX (если есть)
   - Или подключите DMX устройство и проверьте работу

## Устранение проблем

### ESP32 не отправляет данные
- ✅ Проверьте, что `TEST_MODE = false` в коде
- ✅ Проверьте подключение GPIO12 к DI на MAX485
- ✅ Проверьте подключение GPIO14 к DE+RE на MAX485

### DMX устройства не реагируют
- ✅ Проверьте полярность A/B на DMX кабеле
- ✅ Установите терминатор 120Ω на последнем устройстве
- ✅ Проверьте адреса DMX устройств (должны быть настроены правильно)
- ✅ Убедитесь, что кабель DMX не поврежден

### Нестабильная работа
- ✅ Используйте качественный экранированный DMX кабель
- ✅ Установите терминатор на последнем устройстве
- ✅ Проверьте длину кабеля (рекомендуется <100 метров без усилителей)
