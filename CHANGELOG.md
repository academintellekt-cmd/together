## [Unreleased]

### Исправлено
- **DMX**: Исправлена логика вычисления адресов каналов для правильной работы каждого фонаря отдельно
- **DMX**: Исправлена функция switchTab для правильной работы вкладок в веб-интерфейсе
- **DMX**: Добавлено детальное логирование для диагностики работы каналов

### Изменено
- **DMX**: Обновлены названия каналов LM70S согласно спецификации:
  - Канал 1: Угол по оси X (0-255)
  - Канал 2: Угол по оси Y (0-255)
  - Канал 3: Режим работы (0-8=ВЫКЛ, 9-135=Затемнение, 136-240=Стробоскоп, 241-255=ВКЛ)
  - Канал 4: Затемнение КРАСНЫЙ (0-255) - RGB R
  - Канал 5: Затемнение ЗЕЛЕНЫЙ (0-255) - RGB G
  - Канал 6: Затемнение СИНИЙ (0-255) - RGB B
  - Канал 7: Затемнение БЕЛЫЙ (0-255)
  - Канал 8: Скорость (0-255)
  - Канал 9: Сброс настроек (150-200)
- **DMX**: Обновлены RGB каналы с 7,8,9 на 4,5,6 во всех компонентах системы (веб-интерфейс, сервер, ESP32)
- **Документация**: Обновлены все инструкции по ESP32 и DMX с новой информацией о каналах

### Добавлено
- Создан `hub-layout.css` с общими стилями для HUB-зон
- Объединена документация в `docs/SETUP.md`

- Добавлен `CHANGELOG.md` для отслеживания изменений
- **Масштабируемость**: Добавлены лимиты на количество комнат (50) и игроков (500)
- **Масштабируемость**: Ограничение рейтинга в памяти до 1000 записей (вместо 100)
- **Масштабируемость**: Автоматическая очистка неактивных комнат (30 минут неактивности)
- **Масштабируемость**: Батчинг записей в Google Sheets (группировка по 10 записей)
- **Масштабируемость**: Мониторинг производительности (логи каждую минуту)
- **Масштабируемость**: Отслеживание активности комнат (lastActivity)
