# 📦 Установка и запуск

## Проблема: Node.js не найден

Если при запуске вы видите ошибку "Node.js не найден", выполните следующие шаги:

## ✅ Решение 1: Установка Node.js (рекомендуется)

1. Откройте https://nodejs.org/
2. Скачайте **LTS версию** (Long Term Support)
3. Установите скачанный файл `.pkg`
4. Перезапустите терминал
5. Запустите: `./start.sh`

## ✅ Решение 2: Через Homebrew

```bash
# Установите Homebrew (если еще не установлен)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установите Node.js
brew install node

# Запустите сервер
./start.sh
```

## ✅ Решение 3: Проверка установки

После установки проверьте:
```bash
node --version
npm --version
```

Должны увидеть версии, например:
```
v20.11.0
10.2.4
```

## ⚠️ Важно

- Открывайте страницы через `http://localhost:3000/host.html`
- НЕ открывайте файлы напрямую через `file://`
- Сервер должен быть запущен (не закрывайте терминал)
