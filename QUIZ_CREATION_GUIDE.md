# Руководство по созданию нового квиза

## Шаг 1: Создание конфигурации квиза

### Автоматическое создание (рекомендуется)

Используйте скрипт для автоматического создания нового квиза:
```bash
node create-quiz.js <quiz-id> [quiz-name]
```

**Примеры:**
```bash
node create-quiz.js "corporate-2024-01" "Корпоратив 2024"
node create-quiz.js "birthday-anna-2024" "День рождения Анны"
```

Скрипт автоматически создаст:
- Файл конфигурации квиза: `data/quizzes/{quiz-id}.json`
- Файл с вопросами: `data/questions/{quiz-id}.txt`

### Ручное создание

Скопируйте шаблон и создайте новый файл:
```bash
cp data/quizzes/template.json data/quizzes/{quiz-id}.json
cp data/questions/template.txt data/questions/{quiz-id}.txt
```

### Заполните конфигурацию:

```json
{
  "id": "event-2024-01",                    // Уникальный ID квиза (латиница, без пробелов)
  "name": "Название квиза",                 // Полное название
  "description": "Описание",                // Краткое описание
  "icon": "🎮",                             // Эмодзи иконка
  "soloMode": true,                         // Поддержка одиночной игры
  "multiplayerMode": true,                  // Поддержка мультиплеера
  "password": "1234",                       // Пароль (если нужен)
  "passwordRequired": true,                 // Требуется ли пароль
  "colors": {                               // Цвета карточки
    "background": "#abf67c",
    "text": "#2fb95d",
    "shadow": "rgba(47, 185, 93, 0.3)"
  },
  "display": {                              // Тексты для отображения
    "title": "НАЗВАНИЕ КВИЗА",
    "subtitle": "подзаголовок",
    "phrase": "забавная фраза",
    "questionsDisplay": "15 из {total}",
    "timeDisplay": "по {time} сек"
  },
  "gameSettings": {
    "questionsPerGame": 15,                 // Сколько вопросов в игре
    "totalQuestions": 0,                    // Всего вопросов (заполнится автоматически)
    "defaultTime": 15,                      // Время на вопрос по умолчанию
    "maxPlayers": 14                        // Максимум игроков
  },
  "questionsFile": "event-2024-01.txt"     // Имя файла с вопросами
}
```

## Шаг 2: Создание файла с вопросами

Создайте файл с вопросами:
```bash
cp data/questions/template.txt data/questions/{quiz-id}.txt
```

### Формат вопросов:

```
Q: Текст вопроса?
A: Вариант ответа 1
A: Вариант ответа 2
A*: Правильный ответ (помечен звездочкой)
A: Вариант ответа 4
T: 15

Q: Следующий вопрос?
A: Вариант 1
A*: Правильный ответ
A: Вариант 3
A: Вариант 4
T: 20
```

**Правила:**
- Каждый вопрос начинается с `Q:`
- Варианты ответов начинаются с `A:`
- Правильный ответ помечается `A*:` (звездочка)
- Время на вопрос указывается как `T: X` (в секундах)
- Вопросы разделяются пустой строкой
- Минимум 4 варианта ответа на вопрос

## Шаг 3: Проверка

После создания файлов:
1. Перезапустите сервер
2. Проверьте, что квиз появился на главной странице
3. Протестируйте оба режима (solo и multiplayer)

## Автоматически доступные функции

При создании нового квиза автоматически доступны следующие функции:

### 🎮 Джойстик
- **Автоматически работает** во всех режимах (solo, multiplayer)
- Кнопки 1-4 для выбора вариантов ответа (А, Б, В, Г)
- Кнопка 9 для перехода к следующему вопросу / готовности
- Настройка джойстика: `/joystick-test/joystick.html`
- Конфигурация сохраняется в `data/joystick-config.json`

### 💡 DMX Освещение
- **Доступно** через прямые ссылки:
  - Пульт управления: `/dmx-control.html`
  - Конфигурация DMX: `/dmx-config.html`
  - Создание сценариев: `/dmx-showmaker.html`
- Конфигурация сохраняется в `server/dmx/dmx-config.json`

### 📱 Использование
- Все новые квизы автоматически поддерживают джойстик и DMX
- Не требуется дополнительная настройка при создании квиза
- Функции доступны через интерфейс игры
